# 给 GPT 的提示词（关联动量新猜想）

> 用法：把本目录整包发给对方（6 份文档），然后贴下面的**第一轮**提示词。
> 拿到回答后再贴**第二轮**提示词 —— 分两轮是为了先拿到"值不值得做"的裸判断，不被方案细节稀释。
> 目录清单与校验和见 `MANIFEST.md`。

## 第一轮：值不值得做

```
这是一个 A 股量化研究项目。它的验证流程是"证伪型"：

  先量信息容量（投影到现有价格主成分基，算 R² 与 PR 净增）
  → 正交性阶梯 + 控制集 2^11 穷举
  → surrogate 循环平移噪声底
  → 训练/测试切分 + Bonferroni / BH-FDR

失败要归档 5 种死因码（F1 多重检验未校正 / F2 样本外归零 / F3 共同暴露换皮 /
F4 跨期符号相反 / F5 本来就无信号）；同一个死因码出现第二次即停手。
项目当前在停手期（至 2027-04-11，禁止新增防线）。
项目历史：换道胜率 0/3，通过它自己全部防线的候选 0 个。
它刚刚否掉了一份"换数据"的计划（基本面数据源），过程见 `基本面数据源计划.md`。

我现在要评估一个新方向：`新猜想论证.md`。
它承接 `阶段性报告.md` §4.3，把原来的"一只 B 先行、A 跟随"升级为
"一组有外生依据的关联公司（10~30 只）+ 时序溢出"。

【先读这几份】`研究方法与验证协议.md`、`死因码表.md`、`阶段性报告.md` 的 §3 与 §4，
然后读 `新猜想论证.md`。

读 `研究方法与验证协议.md` 是硬要求：不读它，你给出的建议会是通用量化常识，
而通用量化常识恰好是这个项目已经证否过的那套。

【我只要三件事，按这个顺序回答】

一、值不值得做（一句话结论 + 理由）
   我会先看这一句。如果你认为不值得，后面不用展开。

二、最可能的死法（最重要）
   1. 对着五环节漏斗（第 0 数据 / 第 1 判重 / 第 2 裸 IC / 第 3 正交化 /
      第 4 噪声底 / 第 5 分层）指一个最可能的死亡点，并说明理由。
   2. `阶段性报告.md` §3.1 记录了本项目上一个同族失败：
      H4 邻居同步，表面 IC +0.39 / IR +3.53，剔掉共同暴露后超额反转
      IC −5.5% / IR −0.58，判 F3 全灭。
      我的新猜想把"同期"改成了"时序"。请直接判：这一改是否真的能躲开 H4 的死因，
      还是只是换个姿势重蹈 F3？
   3. `新猜想论证.md` §4 第 4 类来源是"共同机构持仓"，文献 Antón & Polk (2014)
      证明共同持仓本身就能解释横截面相关性与收益。共同持仓数据是公开的。
      请判：它能不能直接解释掉任何关联动量？要事先怎么设计对照才能排除 F3，
      而不是事后解释？

三、怎么改（要具体、可执行）
   1. `新猜想论证.md` §4 列了 4 类关系图来源（分析师共同覆盖 / 供应链 / 文本相似 /
      共同持仓）。哪个最省且最不可能踩 F3？如果都不行，有没有第 5 类我们漏掉了？
   2. `新猜想论证.md` §3 的机制行：它写的是"注意力与覆盖是硬约束"。
      项目的规则 1 要求机制回答"谁在被迫以错误价格交易、他为什么改不了"。
      我刚被否掉的那份计划，机制写成"被动资金被合同强制按权重持有"，被判为
      "约束 ≠ 错误定价"（见 `基本面数据源计划.md` §15.2）。
      请直接判：本条机制是否同样不够格？请明说，不要和稀泥。
   3. §5 的三组事先对照（时序 vs 同期 / 共同持股控制 / 同行业安慰剂）够不够？缺什么？
   4. 如果这个项目只能做一件事：先做关系图的数据可获得性实测（第 0 步），
      还是先做判据与对照设计？

四、你不知道的部分
   明确列出你需要什么信息才能给出确定判断。

【禁止】
- 不要说"值得进一步研究""思路有价值"这类话。
- 不要建议：多因子加权 / 加止损 / 优化仓位 / 上深度学习或 GNN /
  放宽判据 / 换个阈值 / 多试几组参数。
  这几类恰好是这个项目已经证否过、或停手期明令禁止的。
- 不要只讲文献，必须结合 `阶段性报告.md` §3 的本项目实测数据下判。

【输出格式】
结论先行。每条建议必须能直接执行（写明动哪个文件、做什么、判断标准是什么）。
```

## 第二轮：要具体方案（拿到第一轮回答后再发）

```
上一轮你的结论是【填你的结论】。

现在请把它落成一个可执行的第 0 步，格式按本项目已有计划文档的惯例：
漏斗式（每步写终止条件 + 对应死因码），不新增任何防线，不撞停手期。

请给出：

1. 数据可获得性实测清单：每一类关系图来源，具体去哪个数据源、拉什么字段、
   怎么验证历史深度、怎么验证发布滞后（前视闸门）。
2. 前视闸门的具体口径：分析师覆盖 / 基金持仓 / 年报客户都是滞后数据。
   怎么按"实际可得日"对齐而不是按报告期回填？拿不到发布时点怎么办？
3. §5 三组对照的具体实现：控制变量怎么加、安慰剂怎么造、
   哪一组对照不成立就应当直接终止。
4. 多重检验计数口径（这是上一份计划被挑出的第二个毛病）：
   本方向预计会产生多少次检验？哪一些属于同一个多重比较族？
   Bonferroni 的分母是什么？BH-FDR 适用哪个集合？
5. 按你的判断，这条路的期望成本是多少天？在哪一步最可能 0 成本终止？

不要写代码，只要方案。不要给我"可以考虑"这类模糊表述。
```

## 沟通上的三条经验（本项目已验证过）

1. **必须先给判法文档，再给被审对象。** 上一轮我只给了计划不给协议，对方就会用通用量化常识审 —— 那正好是本项目已经证否的那套。
2. **一次只问一类问题。** 上一轮把"值不值得做"和"合规不合规"混在一起问，拿到的是十条合规判定，没有对方向本身的价值判断。
3. **要求它直接判"够不够格"，不许和稀泥。** 本项目机制闸门是二值的，含糊回答等于没回答。
