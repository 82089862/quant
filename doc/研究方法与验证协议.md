> 本文记录 `quant/` 里所有**证伪型**测试的共同逻辑。
> 目的：任何新想法进来，先按这套流程筛一遍，避免重复踩同一个坑。
> 每个环节都配一条**真实踩过的坑**作为它存在的理由——没有实测支撑的环节不写进本文。

## 0. 一句话总纲

**失败的原因收敛，成功的原因发散。**

本目录历史上做过 4 次挖掘尝试，全部失败。把它们摆在一起看，失败集中在一个很小的原因集合里：
不是"没想到好点子"，而是**同一个统计学错误换了 4 张皮**。所以研究流程的价值不在"帮你找到因子"，
而在**提前拦住那几类必死的情况**。

## 1. 前提与环节①：先量信息容量，再谈策略

数据决定上限，策略只决定你离上限多远。所以第一件事不是写因子，是**量出数据里到底有几个独立维度**。

### 1.1 输入

| 项 | 值 |
|---|---|
| 原始数值列 | **8** — `open` `high` `low` `close` `volume` `amount` `outstanding_share` `turnover` |
| 合法派生特征 | **23**（全部由上面 8 列算出，无外部数据，见 `stocks/capacity.py:FEATURES`） |
| 面板规模 | 11,450,179 行 / 5,476 只 / 2015-01-05 ~ 2026-10-09（2026-10-11 补退市股后的当前口径；旧口径 11,022,483 / 5,223） |

### 1.2 度量方法

1. 每个截面内对特征做 **rank**（转成 Spearman，免疫共同因子的量纲）
2. 对 rank 后的矩阵做 PCA，得特征值谱 `λ`
3. 建一个 **iid 均匀零假设谱**作为参照底线（纯噪声应该长什么样）

两个"有效维度"定义：

- **PR（参与率）** = `(Σλ)² / Σλ²` —— 谱有多"平"，抗单点尖峰
- **n90** = 累计解释 90% 方差所需的 PC 个数 —— 好理解的整数

### 1.3 实测结果（`uv run stocks/capacity.py --sample 25`）

```
原始数值列          8
合法派生特征        23
有效维度 PR         7.5        90% 方差只需 11 个主成分
第一主成分          6.08       (纯噪声基准 0.98，6.2x)
有效维度 单日 11 维   6.14
有效维度 全部 23 维   7.54      多日窗口净增 +1.40
```

特征值谱（对照噪声底）：

| PC | 实测 λ | 噪声底 λ | 判读 |
|---|---|---|---|
| 1 | 6.076 | 0.981 | 6.2 倍，强共同因子 |
| 2 | 3.843 | 0.984 | |
| 3 | 2.677 | 0.986 | |
| 4 | 1.991 | 0.988 | |
| 5 | 1.467 | 0.990 | |
| 6 | 1.285 | 0.991 | 前 6 个 PC = 75% 方差 |
| 7 | **0.970** | 0.993 | **跌到噪声底以下** |
| 8~23 | ≤0.866 | ~0.995 | 全在噪声里 |

**结论：8 个数值列 = 7.5 个独立维度。** 23 个派生特征里有 15 个以上是噪声或冗余。

### 1.4 一个反直觉的发现：冗余是"全局低秩"，不是"成对相关"

- 成对 |Spearman| ≥ 0.90 的只有 **1 对**：`vol20` / `park20` = 0.9127
- 但每个特征对**其余 22 个**做回归的 R² 是 **0.50 ~ 0.95**

| 特征 | 对其他 22 个的 R² |
|---|---|
| `vol20` | 0.948 |
| `log_mv` | 0.921 |
| `log_amt` | 0.918 |
| `intra` | 0.913 |
| `ret1` | 0.903 |
| `park20` | 0.878 |
| … | … |
| `lower_sh` | 0.501 |
| **中位数** | **0.82** |

**这意味着：靠"看相关性表"找冗余是找不到的。** 任意两个特征单独看都不像重复，
但整组一起看就是低秩的。必须用 PCA 或多元 R²，不能只看相关矩阵。

### 1.5 判据：新想法先投影，>0.95 直接扔

`capacity.basis_r2(basis, x)` —— 把新想法投影到已有基上算 R²：

- **R² > 0.95** → 不含新信息，不必回测
- **R² < 0.95 且 PR 净增 ≥ 0.5** → 有正交维度，进入环节③

**实测反例**：追加 3 个"全新"价格特征（10 日动量 / 10 日波动 / 5 日换手标准差），
PR 变化 **−0.34**。零新增信息——因为它们在 7.5 维空间里已经有等价物。

## 2. 环节②：新数据源的信息含量（`stocks/margin_probe.py`）

外部数据要花钱花时间接，接之前先量它带来几个新维度。

### 2.1 判据

| PR 净增 | 判读 |
|---|---|
| ≥ +0.5 | 真新维度，值得写管道 |
| +0.1 ~ +0.5 | 弱，看别的理由 |
| ≤ +0.1 | 同族数据，别接 |

### 2.2 实测：融资融券（`uv run stocks/margin_probe.py --step 3`）

```
对比样本          345,228 行 / 168 个截面 / 3814 只股票
面板 673,134 行 -> 有融资融券 345,228 行 (51.3%)
价格特征 23 维     PR = 7.31
加 5 个融资特征     PR = 9.27    净增 +1.95
```

> 2026-10-12 重跑：面板补退市股后样本变大（338,274 → 345,228 行 / 3689 → 3814 只 / 52.1% → 51.3%），
> 同时把 `m_bal_chg` 的口径与 `margin_factor.py` 对齐（`pct_change(fill_method=None)`，见 `margin_probe.py`）。
> PR 末位 9.25 → 9.27，**净增仍 +1.95**，结论不变。

三个同口径对照：

| 加进去的东西 | PR 净增 | 判读 |
|---|---|---|
| 12 个价格时间窗特征 | +1.40 | 有信息但同族 |
| 3 个"全新"价格特征 | **−0.34** | 零新增 |
| **5 个融资融券特征** | **+1.95** | **真新维度** |

每个融资特征落在价格主成分基上的 R²：

| 特征 | R² | 含义 |
|---|---|---|
| `m_buy_int` 融资买入额/成交额 | **0.014** | 几乎完全正交 |
| `m_bal_chg` 融资余额月环比 | 0.055 | 正交 |
| `m_short_ratio` 融券余量/流通股本 | 0.174 | 部分重合 |
| `m_shortsell_int` 融券卖出量/成交量 | 0.194 | 部分重合 |
| `m_bal_ratio` 融资余额/流通市值 | **0.671** | 一半是规模/换手的影子，**别用** |

### 2.3 必须区分两件事

**"+1.95 维" 是信息含量，不是"可交易"。** 这两件事完全独立：

- 信息含量：这批数据是否携带价格数据里没有的东西 → **是**（+1.95）
- 可交易性：这些新维度能不能变成选股信号 → **见环节③，答案是不能**

环节②只回答第一个问题。**信息在，不等于用得上。**

## 3. 环节③：正交性阶梯（共同暴露预检）—— 核心

这是本文**最重要**的环节，也是本项目历史上付出代价最大的一课。

### 3.1 为什么单独讲：另外三道防线都拦不住共同暴露

| 防线 | 拦得住什么 | 拦不住什么 |
|---|---|---|
| Bonferroni / BH-FDR | 假阳性率 | 拦不住"重复计数"（同一个原因被算成多个因子） |
| surrogate 噪声底 | 数值上是否高于纯噪声 | **只测"是否相关"，测不出"相关来自共同暴露"** |
| 训练/测试切分 | 跨期不稳定 | **共同暴露在两个期同样稳定 → 稳定地骗你** |
| **正交性阶梯** | **共同暴露** | 唯一拦得住的 |

### 3.2 做法：控制集阶梯

对候选因子逐档做**截面回归取残差**，在残差上重算 IC。
档位按"从少到多"排，因为**关键信息藏在衰减的形状里，不在某个单元格里**：

```
无控制 → 仅规模 → 仅流动性 → 规模+换手(2个) → 规模+流动性(4个) → 动量+波动(7个) → 全部11个
```

### 3.3 三条判读规则

| 形状 | 判读 |
|---|---|
| **某个单变量就翻转符号** | **确凿换皮**，不可能是过控制 |
| **逐档单调衰减**（每加一档掉一截） | **共同暴露指纹**，即使最终没翻转也判为换皮 |
| **少变量完全不动、多变量突然吃掉** | 过控制嫌疑 → 残差仍算数，但要用 §3.5 的量级裁决 |

### 3.4 实测：融资融券 5 个因子（`stocks/margin_factor.py` 控制集阶梯）

测试期（2021-2026，70 期）残差 IC，`!` = 相对「无控制」符号翻转：

| 因子 | 无控制 | 仅规模 | 仅流动性 | 规模+换手(2) | 规模+流动性(4) | 动量+波动 | 全部11个 |
|---|---|---|---|---|---|---|---|
| `m_buy_int` | +0.0114 | +0.0067 | +0.0113 | +0.0104 | +0.0047 | +0.0025 | +0.0010 |
| `m_bal_chg` | -0.0171 | -0.0168 | **+0.0011 !** | +0.0018 ! | +0.0092 ! | +0.0068 ! | +0.0117 ! |
| `m_short_ratio` | **-0.0559** | -0.0343 | -0.0278 | -0.0130 | **+0.0115 !** | -0.0124 | +0.0135 ! |
| `m_shortsell_int` | -0.0454 | -0.0155 | -0.0682 | -0.0437 | -0.0107 | -0.0290 | -0.0075 |
| `m_bal_ratio` | +0.0004 | -0.0417 ! | +0.0382 | -0.0161 ! | +0.0039 | +0.0093 | -0.0051 ! |

**三条不同死因，全部落在这套阶梯的判读规则里：**

| 因子 | 死因 | 阶梯给出的证据 |
|---|---|---|
| `m_bal_chg` | **换手率换皮** | `仅流动性` 一个变量就翻转（-0.0171 → +0.0011）→ 规则① |
| `m_short_ratio` | **规模+流动性联合换皮** | 单调衰减 -0.0559→-0.0343→-0.0278→-0.0130→+0.0115 → 规则② |
| `m_shortsell_int` | **跨期不成立** | 证据①训练期 IC +0.0082 / 测试期 -0.0430 **符号相反**；证据②穷举 2048 个子集后 `log_amt`/`illiq20` **单个变量**即可把 \|残差 IC\| 打到量级线下（§11.4），故原判据「单档都吃不掉」是 7 档手选集的遗漏 |
| `m_buy_int` | **本来就无信号** | 所有控制集下 \|IC\| ≤ 0.0114 |
| `m_bal_ratio` | **无信号 + 共线不稳** | IC 在控制集间乱跳：+0.0004 → -0.0417 → +0.0382 → -0.0161 |

> **7 档是手挑的，不是完备的。** 上表只覆盖 7 个控制集；占满 2¹¹ 个子集后
> `m_shortsell_int` 出现了手挑集里没有的"单变量就能吃掉"案例。档位越少，
> "过控制还是换皮"越难判 —— 完整解法见 §11.4。

### 3.5 最终裁决：不看 p 值，看量级

即使对最乐观的解释（把 `m_short_ratio` 的衰减算作过控制），残差 IC 也只有 -0.013、**ICIR < 0.3**。

对比本项目**唯一验证过的真实因子**：

| | IC | ICIR |
|---|---|---|
| 20 日反转（**定 KILL 判据时的口径**，140 期，分层 G1 -55.79% / G5 +212.87%） | **-0.0704** | **-0.46** |
| 同上，2026-10-11 补退市股后（G1 -58.16% / G5 +136.42%） | -0.0686 | -0.45 |
| `m_short_ratio` 最乐观残差 | -0.013 | < 0.3 |

**不到 1/5。裁决：不值得为它写任何管道。**

> **规则：残差 IC 的 ICIR < 0.3，或 \|残差 IC\| < 已知真实因子的 1/5 → 判定不可用，停止投入。**
>
> **KILL 线取 0.0704/5 = 0.0141，不随数据更新而挪**：补退市股后真实因子 IC 变 0.0686（即 0.0137），
> 但判据必须事先定死，事后跟着数据调等于把自由度还给「挑阈值」（与 §11.4 第三条同一个道理）。留痕见 `doc/stocks/Alpha191候选分层回测计划.md` §4 变更留痕表。

### 3.6 两个必须记住的陷阱

**陷阱一：小 R² 也能吃掉小 IC。**
`m_short_ratio` 被价格因子解释的方差只有 **13.4%**（对比：23 个价格特征彼此之间的多元 R² 中位数是 **0.82**）。
在这个数据里 13.4% 看起来微不足道——但 0.05 量级的 IC 就是被这 13.4% 搞归零甚至翻转的。
**不要因为 R² 低就认为因子独立。**

**陷阱二：控制变量共线会让系数不稳。**
`m_short_ratio` 从「规模+换手（2 个）」的 -0.0130 跳到「规模+流动性（4 个）」的 +0.0115，
变化幅度 0.0245 而只多了 2 个**高度共线**的变量（`log_amt` `illiq20` 与已有的 `log_mv` `turnover_lv` 同族）。
`m_bal_ratio` 的 IC 在 -0.042 到 +0.038 之间乱跳也是同一个症状。
**所以判读必须看整条序列的形状，不能只看单个单元格；而且必须配一个 2 变量精简集做对照。**

## 4. 环节④：surrogate 噪声底

**做法**：保留因子的边际分布、破坏因子-收益关系，跑同一套统计量，看纯噪声能走多远。

**实现技巧**（`stocks/margin_factor.py:ic_series`）：在**每个截面内**打乱因子值的配对。
因为 rank 不受置换影响，所以置换后的 IC 只是「同一个 rank 向量的重排」与收益 rank 的内积——
预计算一次 rank 和模长，300 次 surrogate 几乎零成本。

实测噪声底（两融测试期，70 期平均 IC）：

| 因子 | 噪声底 \|IC\| | 观测 \|IC\| |
|---|---|---|
| `m_buy_int` | 0.0021 | 0.0119 |
| `m_bal_chg` | 0.0021 | 0.0182 |
| `m_short_ratio` | 0.0022 | **0.0525** |
| `m_shortsell_int` | 0.0022 | 0.0430 |
| `m_bal_ratio` | 0.0022 | 0.0014 |

**5 个因子全部通过（p ≈ 0.000）。而它们全是换皮。**
这就是为什么 surrogate 必须配合环节③——**它是一道必要但不充分的防线。**

`stocks/leadlag.py` 里还有一条更严格的经验：**纯噪声也能有 9 个配对通过 Bonferroni。**
说明正态近似阈值不可靠，**唯一可信的判据是「显著数是否超过噪声底」**。

## 5. 环节⑤：训练/测试切分 + 多重检验

### 5.1 切分

固定 **训练 2015-2020 / 测试 2021-2026**。**只报测试集留存，不报训练集。**

### 5.2 多重检验

- 检验次数必须显式报出来（否则等于隐瞒了假阳性数量）
- **Bonferroni**（严格）与 **BH-FDR**（宽松）同时报
- 只报名义 5% 等于报假阳性：`26,115 × 5% = 1,305` 个

### 5.3 实测：时序滞后联动（`stocks/leadlag.py`，锚点 sz300359）

5223 只候选 × 滞后 1~5 日 = **26,115 次检验**：

| 切片 | 名义显著(5%) | Bonferroni | FDR |
|---|---|---|---|
| 训练 2015-2020（1462 日） | 3,171（12.1%） | 7 | 28 |
| 测试 2021-2026（1395 日） | 1,667（6.4%） | **0** | **0** |

训练集 top-50 配对在测试集留存 **3/50 = 6.0%**，surrogate 噪声底 **2.9%**。

**结论：本口径下未发现可复现的先行-滞后关系。** 训练集最强配对（ccf 0.158，p=1.2e-9）
在测试集归零（ccf 0.0019，p=0.945）。

同一脚本里的**市场指数剔除**实测（对应环节③的雏形，但只对单一市场因子）：
名义显著 12.0% → **7.0%**，而纯噪声底 **5.1%**。即原始口径下**一半以上是共同因子**。

> `stocks/leadlag.py` 的 `residualize` 只对**市场等权指数**正交化，**不够**。
> 完整的做法是环节③：对整个价格因子集做阶梯正交化。

### 5.4 涨跌停过滤（易漏）

信号日涨跌停的样本必须剔除。涨停买不到、信息延到次日，会**伪装成预测力**——
那是交易制度产物，不是市场规律。`stocks/leadlag.py` 实测剔除 1.52% 样本。

## 6. 完整流程：新想法进来照这个顺序走

```
① 信息容量盘点          stocks/capacity.py
   └─ 投影到已有基，R² > 0.95 ? ──是──> 停（无新信息）
        │否
② 信息含量实测          stocks/margin_probe.py 式
   └─ PR 净增 < 0.5 ? ──────────是──> 停（同族数据）
        │否
③ 正交性阶梯 + 控制集穷举 ★核心★
   ├─ 7 档阶梯粗筛       stocks/margin_factor.py（手挑档位，只作粗筛）
   └─ 穷举 2¹¹ 个子集     stocks/dominance.py（决定性，2 分钟）
        └─ 单变量就吃掉 / k≤2 被吃掉 ? ─是──> 停（换皮，并指名是哪一维）
        └─ 残差 ICIR < 0.3 ? ──────────是──> 停（量级不够）
        │通过
④ 训练/测试 + surrogate + 多重检验
   └─ 测试集符号不一致 / 未超噪声底 ? 是──> 停
        │通过
⑤ 分层回测（扣成本、查换手、算容量）
   └─ 才算"候选"，仍不是"能上"
```

**每一关都是"证伪关"，不是"确认关"。** 设计上宁可错杀，因为在这个领域
「错杀」的成本是少一个因子，「漏过」的成本是真金白银。

## 7. 已实测的失败案例总表

| 案例 | 规模 | 死因 | 拦不住的防线 | **唯一拦住的** |
|---|---|---|---|---|
| `stocks/downturn.py` 尾部传染 | 20,888 次检验 | 训练集 lift 1.5~1.6 → 测试集归零到 0.89~0.99 | 名义显著性、Bonferroni | 样本外留存 |
| `stocks/leadlag.py` 时序滞后 | 26,115 次检验 | 训练集 7 个 Bonferroni 显著 → 测试集 **0** 个 | 名义显著性、FDR | 样本外留存 + 噪声底 |
| 邻居同步（脚本已删） | — | **IC +0.39 / IR +3.53 全是 beta（共同暴露）** | surrogate、训练/测试 | **正交化** ★ |
| `stocks/margin_factor.py` 两融 | 142 期末 / 5 因子 | 2 个换皮 + 1 个跨期反号 + 2 个无信号 | **surrogate（全部 p≈0.000 通过）**、训练/测试（两期同号） | **正交性阶梯** ★（只挡了一部分，见 §11.4） |

**读这张表的正确方式**：每加一道防线，都是被前一道防线漏掉的案例逼出来的。

- 名义显著性 → 被 `downturn` 逼出 **Bonferroni/FDR**
- Bonferroni/FDR → 被 `leadlag` 逼出 **样本外留存**
- 样本外留存 → 被「邻居同步」逼出 **正交化**
- 只对市场指数正交化 → 被「两融」逼出 **正交性阶梯**（对完整因子集）
- 正交性阶梯（手挑 7 档）→ 被「两融控制集穷举」逼出 **全子集穷举 + 优势分析**（§11.4）

## 9. 已知局限（未做，别当成已做）

**方法层面**

- **过控制 —— 已排除（`stocks/dominance.py`，穷举 2¹¹ = 2048 个子集）**。原怀疑：`m_shortsell_int`
  符合"少变量不动、多变量突然吃掉"。实测：11 个单变量里已有 2 个单独就能把 \|残差 IC\|
  打到 0.0141 线下（`log_amt` +0.0076 / `illiq20` +0.0053），且残差 IC 中位数随子集大小
  **单调**从 0.0325 衰减到 0.0075、没有拐点。
  → 原判断是 7 档手选控制集的遗漏，不是过控制。**换皮对象是成交额/流动性族，不是"多变量联手"。**
- **共线控制变量的系数不稳 —— 已量化**。`m_bal_ratio` 的 `log_mv` 单变量 R² 0.556，
  但平均增量 R² 只有 0.354，差额 0.20 分摊给与它共线的 `illiq20`（0.162）/`turnover_lv`（0.195）/`log_amt`（0.083）。
  §3.6 陷阱二的"乱跳"来自这个分摊，不是来自信号。
- **只验证了月度线性口径**。同一个因子的日频口径、事件口径、非线性口径可能给出完全不同的答案——
  两融的正交维度是真的（+1.95），只是月度线性用不出来。
- **`downturn.py` 的判据短一关**。它的 docstring 把判据写成四关（lift + Bonferroni/FDR + 样本外 + surrogate 噪声底），
  但代码只算前三关，**surrogate 在本脚本无实现**（`leadlag.py` / `timing.py` / `margin_factor.py` 各自有）。
  H2 的结论是**证伪**，不依赖这一关，所以已记录的判定未受影响；但谁要拿它当「通过」的判据引用，必须先补上这一关。
- **没有做正式的过拟合概率估计**（如 PBO）。目前的防线是启发式的。

### 11.1 逐环节对照：每一环都有成熟公开对应物

**结论：这套流程不是新东西，是把 1970s–2020s 的统计工具独立重新发明了一遍；每一环都能找到更严格的公开版本。**

| 我们的环节 | 公开对应物 | 差在哪 |
|---|---|---|
| ① 信息容量 / 零假设谱 | 随机矩阵理论（RMT）：Laloux-Bouchaud 1999–2000，把实证特征值谱与 Marchenko-Pastur 噪声谱对比 | 他们用解析的 MP 律，我们用置换零假设谱——**我们的更保守，他们的更优雅** |
| ① 有效维度 PR | Del Giudice《Effective Dimensionality: A Tutorial》；Facco 的 TwoNN；Bahadur《Dimension Estimation of Equity Markets》 | 公式完全一样 `(Σλ)²/Σλ²`。现成的，不必自造 |
| ② 新数据源增量 | Feng-Giglio-Xiu《Taming the Factor Zoo》(JF 2020) 双重选择 LASSO；Barillas-Shanken 跨度检验 | 他们用高维选择方法，我们用 PR 净增——**我们的更糙但更便宜** |
| ③ 正交化 | quant skills 的 `skill-factor-orthogonalize`（agent skill，做法与我们几乎一样）；Barra/Axioma 风险模型中性化 | 他们只做**一档**（行业+规模+风格），**我们有阶梯但他们有行业哑变量** |
| ③ 阶梯的统计形式 | 分层回归 / 增量方差分解（ΔR²）；**优势分析 Dominance Analysis**（Budescu 1993） | 优势分析**穷举所有子集**算平均增量 R²——正好补我们"档位不够、过控制无法排除"的洞（§11.4） |
| ④ surrogate 噪声底 | Theiler 等 1992《surrogate data》（循环平移/相位随机化）；White 2000 Reality Check；Hansen 2005 SPA | **我们的循环平移就是 Theiler 原方法**。White/Hansen 是金融版的规范实现，有现成包 |
| ⑤ 多重检验 + 训练测试 | Harvey-Liu-Zhu 2016：t 阈值应提到 3.0；Barras-Scaillet-Wermers 2010（金融 FDR）；Giglio-Liao-Xiu《Thousands of Alpha Tests》 | 我们是入门版，他们有成套推断框架 |
| ⑤ 回测过拟合 | López de Prado 系列：Deflated Sharpe、PBO、CSCV、《Pseudo-Mathematics and Financial Charlatanism》 | **我们完全没做正式的过拟合概率估计**，这是最大缺口 |
| ⑤ 样本外衰减 | McLean-Pontiff 2016（发表后衰减）；Jensen-Kelly-Pedersen《Is There a Replication Crisis in Finance?》(JF 2023) | 他们量化了衰减幅度 |

### 11.2 三个"近亲"

**近亲 1 — `quantskills/skill-factor-orthogonalize`（GitHub）**：形态最像——它也是个 agent skill，做日频截面 OLS 正交化、剔除行业+规模+风格暴露，输出"暴露归零 + IC 留存"诊断。它的动机描述几乎逐字对应我们的发现（"动量可能只是在买大盘股"）。差别：**它一档，我们七档**（而它多了行业哑变量，我们缺这一维）。

**近亲 2 — 石川《因子投资：方法与实践》（2020）**：中文、A 股、可复制、440 页，覆盖我们环节①②⑤；作者有篇《出色不如走运 (II)？》专讲多重检验怎么排除 data mining 的运气成分。

**近亲 3 — López de Prado《The 10 Reasons Most Machine Learning Funds Fail》(2018)**：把量化失败归纳成 10 条。这是 §0 那个哲学命题（失败的原因收敛）的直接公开对应物。

**另外，这条哲学命题在公开文献里方向是相反的**：Anna Karenina 原则（AKP）认为"成功要求所有要素齐备、失败只要缺一个"→ 成功收敛、失败发散。我们实测支持的是拆成两层后的版本：**失败的"果"发散**（AKP 支持），**失败的"因"收敛**（我们支持：噪声的统计规律与领域无关）。

### 11.3 唯一的原创点 + 成熟替代

公开做法都是**一次性正交化**；没查到谁把"逐档加控制变量、按衰减形状判读换皮 vs 过控制"当成一个**诊断程序**。这是 §3 的原创处。

但它的成熟形式化工具是有的，而且比手挑档位强——**优势分析**：穷举全部 2ᵏ 个子集，对每个控制变量算平均增量 R²（`R²(S∪{j}) − R²(S)` 在所有不含 j 的子集上的均值）。

| | 我们的 7 档阶梯 | 优势分析 |
|---|---|---|
| 做法 | 手挑 7 个控制集 | 穷举全部 2ᵏ 个子集 |
| 治什么 | 换皮 + 过控制 | 共线控制变量谁真的在解释（= §3.6 陷阱二） |
| 结果 | 一条衰减序列 | 每个控制变量的完整重要性排序 |
| 弱点 | **可能漏掉"单变量就能吃掉"的那个变量** | 算力 2ᵏ，k 大时不可行 |

### 11.4 实测：控制集穷举（`stocks/dominance.py`，2026-10-11）

**规模**：11 个控制变量（§3.4 的"全部11个"）的全部 2048 个子集 × 5 因子 × 69 个测试期 = 706,320 次子集回归，耗时 2 分 09 秒。
**自检**：全量控制集（k=11）的残差 IC 与 R² 与 `stocks/margin_factor.py` 逐因子一致（差 < 1e-9）。判据用 §3.5 已有的量级线 **KILL = 0.0704 / 5 = 0.0141**，不自造阈值。

| 因子 | 穷举后的死因 | 依据 |
|---|---|---|
| `m_shortsell_int` | **换皮：成交额/流动性族**（与 §3.4 的"跨期不成立"是两条独立死因，任一条都足够） | 11 个单变量里 `log_amt`/`illiq20` 单独就把它打到 KILL 线下；中位数序列**单调**从 0.0325 衰减到 0.0075，没有"突然掉"的拐点 |

| `m_bal_chg` | 换皮（规则②：少数变量就能吃掉）+ 弱因子 | 11 个单变量里 9 个都在线下，k=1 时 \|IC\| 中位数 0.0095 已跌破线（无控制 IC 只有线高的 1.2 倍） |

| `m_bal_ratio` | 本来就无信号 + 共线不稳 | 无控制 \|IC\| 0.0004 |

| 因子 | 第 1 | 第 2 | 第 3 |
|---|---|---|---|
| `m_bal_ratio` | `log_mv` 0.556 / **0.354**（0.64） | `turnover_lv` 0.195 / 0.081（0.41） | `illiq20` 0.162 / 0.055（0.34） |
| `m_short_ratio` | `log_mv` 0.068 / 0.034（0.50） | `illiq20` 0.062 / 0.026（0.43） | `log_amt` 0.045 / 0.018（0.41） |
| `m_shortsell_int` | `turnover_lv` 0.024 / 0.014（0.58） | `log_mv` 0.028 / 0.009（0.33） | `illiq20` 0.021 / 0.008（0.37） |
| `m_bal_chg` | `vol20` 0.040 / 0.021（0.54） | `mom20` 0.018 / 0.011（0.60） | `vol60` 0.016 / 0.008（0.54） |

**五、三条结论**

1. **"过控制无法排除"的真实成因是手选档位粒度太粗。** 7 档里 `log_amt`/`illiq20` 只出现在「规模+流动性」这个 4 变量集合中，从未单独试过；单独试时它们各自就能把 `m_shortsell_int` 打到线下（+0.0076 / +0.0053），把 `m_short_ratio` 打到 +0.0007。修法：**把阶梯换成穷举**（本仓已做）；维持阶梯的话，每个控制族至少要逐个变量单试一次。
2. **共线分摊可以量化，不必只靠"加一个 2 变量精简集"来缓解。** 增量/单变量普遍在 0.33–0.64，即单变量 R² 会把重要性高估 1.5–3 倍（`m_shortsell_int` 的 `log_mv`：0.028 → 0.009）；`m_bal_ratio` 的 `log_mv` 有 0.20 的 R² 是与 `illiq20`/`turnover_lv`/`log_amt` 共享的。
3. **量级裁决不变，0/5 不变。** 扣掉所有 11 个已知控制变量后（k=11），5 个因子的 \|残差 IC\| 全部 ≤ 0.0135，在 §3.5 的线（0.0141）下。
   但穷举暴露一个新风险：**控制集本身就是一个自由度**——`m_shortsell_int` 在 k=6 的某个子集里 \|IC\| 还有 0.0469，到 k=11 只剩 0.0075；`m_bal_ratio` 同样从 0.0377 掉到 0.0051。想保住结论就总能挑到一个控制集。
   → 判据必须**事先**定死在 k=11（全集）+ 量级线；穷举的实际用途是把"控制集选择"从自由度变成一条分布。

## 12. 适用边界：这套流程对哪类交易友好

> **口径声明**：§12.2–§12.3 是**从本仓判据结构直接推出**的（判据本体 = 截面 rank IC、月频口径、量级线 KILL），
> 属**推理**，不是新实测；带「实测」标的数字是引用前文。§12.5 关于时序 / 期货的部分**未在本仓实测**，标 ⚠。
> 写这一节的动机：前 11 节散落着「适用什么」，从没有一处写「**不适用什么**」。

### 12.1 一句话

**判据的形状决定适用的形状。** 本流程的形状 = **宽横截面 + 低换手 + 强信号 + 有控制集可正交化的排序型策略**。

理由是结构性的：五环节里最核心的 §3（正交性阶梯 / 控制集穷举）和第①关②关全都吃「截面」，
判据本体是同一时点上的**排序**（rank IC）。没有横截面，第③关没有可执行的对象。

### 12.2 六条必要条件（逐条给出处）

| 条件 | 为什么必须 | 出处 |
|---|---|---|
| **宽横截面**（品种 × 时间面板） | 判据本体是截面 rank IC；无横截面则 IC 无定义，核心的 §3 无法执行 | §1.1 §3.1 |
| **低频（月频）** | 信号 = 每月末收盘、执行 = 次一交易日开盘；且全流程**未扣冲击成本** | `stocks/factors.py:3`、§9 执行层面 |
| **强信号**：\|IC\| ≥ KILL | 量级线 **0.0141** = 定判据时的真实因子 IC 0.0704 的 1/5（补退市股后实测 0.0686，**KILL 仍保持 0.0141**，不跟着数据挪）；不到线直接按 F5 停投 | §3.5 §11.4 |
| **有公认控制变量族** | §3 阶梯与 §11.4 穷举要把 k 个控制变量填进去；无控制集则该关空转 | §3.2 §11.4 |
| **候选数量大**（几十 ~ 上万次检验） | 这套流程本身是为「大量试验 → 同一死因」造的 | §7（20,888 / 26,115 次检验；706,320 次子集回归） |
| **可分散、可做空** | 5 层等权组合；A 股融券贵 → 实际只做多，**IC 数字有水分** | README §因子结果、§9 执行层面 |

→ **最友好的场景：宽市场（A 股这类）的月度横截面选股因子研究**——系统性、低频、多标的、靠分散取胜、信号形态是「排序」。

### 12.3 不适用清单

| 交易类型 | 后果 | 原因 |
|---|---|---|
| 高频 / 做市 / 微观结构 | **覆盖率为 0** | 判据不含延迟、库存、逆向选择；月频口径结构性看不见日内 alpha |
| CTA / 趋势 / 单品种时序 | **判据无定义** | 无横截面 → 第③关（核心那一关）执行不了 |
| 事件驱动 / 并购套利 | **必然 F1 全灭** | 样本稀疏，而协议是「宁可错杀」 |
| 期权波动率 / 期权做市 | 第③关要重建 | 控制集是希腊字母族，不是规模 / 流动性 |
| 择时 / 仓位 / 风控 | **整条流水线不适用** | 这类不产生横截面排序。power 域共用地基时最该警惕的就是这一点（那边评判对象是策略收益，不是 IC） |
| 靠执行 / 参数取胜的策略 | 结构性漏掉 | §9 已写明最大缺口：**无 PBO / Deflated Sharpe 等过拟合概率估计**，也无参数平台期检查 |

### 12.4 两条「会误杀」的提醒

1. **弱但真实的因子会被主动放弃**：F5 + 量级线的组合意味着「不到线就停投」。这是设计取舍（宁可错杀，因为错杀成本是少一个因子、漏过成本是真金白银，§6），不是判错。
2. **执行 / 参数类的优势拿不到证据也拿不到否证**：这类策略在本流程里既过不了关、也证不了伪——因为没有测它的统计量。遇到这类，别拿「跑完了没通过」当结论。

### 12.5 换交易类型时必须替换什么（⚠ 未在本仓实测，仅按判据结构推）

F 码本身**跨域成立**（F1~F5 全是统计学错误，与标的选择无关，死因码表 §跨域同源 已把电力域映射过）；
**不成立的是「判据的载体」**——换到无横截面的交易类型时，码表还能用来命名死因，但五环节要换一套统计量才测得出死因。

| 项 | 股票横截面（现行口径） | 换成时序 / CTA | 换成期货横截面 ⚠ |
|---|---|---|---|
| 判据 | 截面 rank IC + 控制集阶梯 | **§3 不适用**，须另立：regime 稳定性 + 参数平台期 + 成本敏感度 | 可用，但活跃品种仅约 50 → 截面变窄，§4 噪声底抬高、功效下降 ⚠ |
| 收益定义 | 后复权收盘 + 涨跌停过滤（§5.4） | 同左 | 结算价 / 保证金 / 杠杆 / 强平，§5.4 要改口径 ⚠ |
| 数据构造 | 后复权价格 | — | 主力连续是**不复权拼接**，跨月假跳空 —— 本流程未覆盖的新污染源 ⚠ |
| 控制集 | 规模 / 流动性 / 动量 / 波动 共 11 个（§11.4） | 不适用 | 商品同受宏观 / 美元 / 流动性驱动 → **F3 风险上升** ⚠ |

### 12.6 一句话记住

> **这套流程不是「什么都能测」，是「只在有横截面的地方能测」。**
> 判据用的统计量（截面 rank IC、控制集残差 IC、子集穷举）全都以「同一时点上一批标的的排序」为输入；
> 换标的不影响死因码，换掉横截面就会让整条流水线失去对象。
