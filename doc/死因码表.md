# 死因码表（全域共享，只增不改）

> 建立 2026-10-11，2026-10-12 从 `stocks/假设登记表.md` §3 抽出为独立文件。
> **本表不分域。** F1~F5 是统计学错误，不是股票专属；电力域同样会犯（见 §跨域同源）。
> 分域的是假设卡片（`stocks/` 用 `H` 号，`power/` 用 `P` 号），不是这张表。

## 规则

新增码必须在 `首次出现` 写脚本名 + 检验次数，并在 `被哪道防线拦住` 写拦截它的机制。删码不删行，把 `状态` 改 `已废弃` 并写明理由。

## 码表

| 码 | 死因 | 首次出现 | 被哪道防线拦住 | 状态 |
|---|---|---|---|---|
| F1 | 多重检验未校正（名义显著，检验次数 ≫ 样本） | `stocks/downturn.py`（20,888 次检验） | Bonferroni / FDR | 在用 |
| F2 | 样本外不成立（训练集显著 → 测试集归零） | `stocks/downturn.py`（lift 1.5~1.6 → 0.89~0.99） | 样本外留存 | 在用 |
| F3 | 共同暴露换皮（IC 全是 beta / 规模 / 成交额 / 流动性） | 邻居同步（IC +0.39 / IR +3.53） | 正交化 → 子集穷举 | 在用 |
| F4 | 跨期符号相反（训练与测试号不同） | `stocks/margin_factor.py` `m_buy_int` | 训练/测试符号一致检查 | 在用 |
| F5 | 本来就无信号（无控制 IC 已在量级线下） | `stocks/margin_factor.py` `m_bal_ratio` | §3.5 量级线（真实因子 1/5） | 在用 |

## 跨域同源（为什么本表不分域）

| 码 | 电力交易域的同源形态 |
|---|---|
| F1 | 几十个场站 × 几十个策略 = 大量检验，不校正必出假阳性 |
| F2 | 用新能源大发时段拟合的出清/报价模型，换到火电顶峰时段失效 |
| F3 | 风光场站同受一份天气驱动，价格与出力高度共线，策略"信号"多为天气 beta |
| F4 | 报价策略在低价时段有效、高价时段反号 |
| F5 | 无控制的策略收益本来就在成本线下 |

> 依据：`研究方法与验证协议.md` §0 —— **失败的原因收敛**。股票域 4 次失败被认出来是同一个统计学错误换了 4 张皮；把码表分域，等于让每个域把这批错误重踩一遍。
