## 1. 要解决什么

`alpha191_ic.csv` 只给到截面 rank IC。实盘要的是**净值曲线、月胜率、换手**。
本计划把「部分独立」的 14 个候选从「有 IC」推进到「有净值 + 月胜率」，并**事先写死判据**，避免看完结果再定标准。

候选构成：部分独立 14 个，其中 13 个过 Bonferroni（`alpha034` p=3.74e-4 差一点），其中 **8 个符号稳定**、6 个在「无控制 → 全 11 控制」之间符号翻转。

## 2. 前置闸门：机制可写性（读 `stocks/alpha191.py` 公式原文，实测）

| 因子 | 公式（原样） | 类别 | 机制 |
|---|---|---|---|
| a015 | `o/Delay(c,1)-1` | 隔夜跳空 | ✅ 开盘集合竞价的被迫成交 |
| a042 | `-Rank(Std(h,10))*Corr(h,v,10)` | 最高价波动 × 最高价-量相关 | ✅ 情绪盘、筹码不稳 |
| a139 | `-Corr(o,v,10)` | 开盘价-量相关 | ✅ 放量高开＝拉高出货 |
| a107 | `-Rank(o-Delay(h,1))*Rank(o-Delay(c,1))*Rank(o-Delay(l,1))` | 开盘相对昨日区间位置 | ✅ 隔夜信息未出清 |
| a184 | `Rank(Corr(Delay(o-c,1),c,200))+Rank(o-c)` | 日内收益 vs 200 日收盘 | ✅ 日内-隔夜收益分解 |
| a034 | `Mean(c,12)/c` | 价格 / 12 日均值 | ⚠ 与 mom20 同源 |
| a035 | `-1*Min(Rank(Decaylinear(Delta(o,1),15)), Rank(Decaylinear(Corr(v,o),17),7))` | 开盘一阶差 + 量-开盘相关 | ⚠ 混合，含趋势项 |
| a078 | `(m-Mean(m,12))/(0.015*Mean(Abs(c-Mean(m,12)),12))`，`m=(h+l+c)/3` | 布林位置 | ⚠ 与 mom20 同源 |
| a144 | 下跌日 `Abs(c/Delay(c,1)-1)/a` 的 20 日均值 | 下跌日冲击/成交额 | ⚠ 卖压代理，弱 |
| a164 | 上涨日 `1/(c-Delay(c,1))` 的标准化 | 上涨日强度 | ⚠ 弱 |
| a070 | `Std(a,6)` | 6 日成交额波动 | ❌ 非方向性，写不出机制 |
| a081 | `Sma(v,21,2)` | 量能 | ❌ 非方向性 |
| a088 | `(c-Delay(c,20))/Delay(c,20)*100` | **20 日动量＝控制变量 mom20 本身** | ❌ 就是被控制掉的变量 |
| a135 | `Sma(Delay(c/Delay(c,20),1),20,1)` | 20 日动量的平滑 | ❌ 同 a088 |

**两条实测结论（本计划最有价值的部分）：**

1. **符号翻转的 6 个里，a088 与 a135 就是 20 日动量本身**（控制变量 `mom20`）。它们在全 11 控制后符号翻转，是因为与 `mom20` 共线 —— 这实测证明「翻转」是**共线伪影，不是新信号**。
2. **符号稳定的 8 个里有 7 个是隔夜/开盘/日内微观结构类**。这解释了它们为何能活过控制集：`mom20` 是收盘到收盘，而由 `open` 重构出的**隔夜跳空与日内收益是它的正交分量**。
   → 这是唯一一条能通过规则 0.1 的机制线（谁的被迫交易：**开盘集合竞价的流动性提供者 / 情绪单**）。

## 9. 风险

1. **机制同质（最大）**：14 个的机制都能归到「情绪/流动性冲击 → 短期反转」，而这一类正是控制集 `mom20`/`vol20` 代表的东西（87 个已判 F3 换皮就是为此）。§2 的隔夜-日内分解线是唯一能区分开的，**它成立不成立正是这次要验的**。
2. **选择偏差**：14 个是从 147 个里事后挑的 → 回测只作**确认**，不构成独立检验，报告必须写明。
3. **换手可能是真杀手**：这类量价因子年换手可能 >10 倍，扣费后能吃掉全部超额。这是把换手塞进 `curve_stats` 的原因。
4. **口径差一天**：IC 用「月末收盘→月末收盘」，回测是「次日开盘→次日开盘」。不构成前视，但不严格等价。
5. **前视**：公式全用滞后算子（`Delay`/`Delta`/rolling），前视风险低但非零。第一版不加哨兵；若 §4 判活，第二版补「截断面板重算」测试。

## 12. 本轮抓到的代码缺陷（2026-10-11，已修）

3. `np.mean(ic0)` 把 NaN 传给 `orth_verdict` → 命中 `if not np.isfinite(ic_raw)` 分支 → F5。

## 15. 冲击成本估算：静态参与率容量（2026-10-14，口径先冻结）

**性质**：**出口**类工作（README §进度 ⑤），**不新增防线** —— 只出容量读数，不改变任何因子的
在册状态，**不得用未成交占比淘汰因子**（`假设登记表.md` §0 规则 3，停手期至 2027-04-11）。

**动机（数据）**：协议 §9 执行层面已声明「分层回测未扣冲击成本（未成交 2.6% 说明流动性已在挡路）」。
5 个过线因子的年化数字全是不含冲击成本的口径，而 G5 层是小盘集中组 —— 先算出这笔账，
才知道后面做不做组合与市值中性化。

**输入（全部为冻结口径产物）**：
- 候选 = `out/layer_judge.csv` 里 `判定 == 通过`（脚本按此取，**不写死**）；基线 = `reversal20`（= −20 日动量）
- 冻结面板的 `amount`（元，真实成交额）与 `open`/`close`
- 各候选 `out/layers_<name>_5g.csv` 的 G5 净值（只用于对账，不参与估算）

**冻结口径（跑数之前写死）**：
1. **成交额** = 执行日（调仓日）该股的 `amount`（真实成交口径，不用 volume×price 估）。
   `amount` 缺失或 ≤ 0 的成交笔数**单列报出**，不许静默丢弃。
2. **需求金额** = 引擎 trades 的实际成交额 `shares × price`（不另估），买卖两侧都算。
3. **可成交上限** = `参与率 × 当日 amount`；参与率三档 **{1%, 5%, 10%} 并列报**（不选单点，且不当阈值）。
4. **未成交占比** = `Σ max(0, 需求 − 上限) / Σ 需求`，全期 + 逐年。
5. **容量** = 本金从 1 亿等比缩放到 k 倍（需求同比例放大，上限不变），求「未成交占比 ≤ 1%」
   与「≤ 5%」对应的最大本金；用二分求 k，不写近似公式。
6. **方向偏置（必须记住）**：需求只统计**已成交**的笔数（被涨跌停挡掉的不进分母）→ 未成交占比是**偏乐观的下界**；
   顺延到次日的成本、冲击对价格的反馈都不在本次估算内，属未做。

**同源硬闸（不过就非零退出）**：
① 重跑 G5 层的全期年化必须与 `out/layer_judge.csv` 的「全期年化」一致（|Δ| ≤ 1e-9）；
② 调仓期数 = `out/layers_<name>_5g.csv` 的月份数；
③ 买入笔数 > 0，且 `amount` 缺失/异常的笔数按口径 1 报出。

**产物**：`out/impact_check.csv`（逐候选逐年）、`out/impact_check_summary.csv`（全期 + 三档参与率 + 容量）；
脚本 `stocks/impact_check.py`。

**不做**：顺延成本、冲击的价格反馈、整手约束、择时/组合权重（均另立任务，不挤进本次）。

   （7.60%~15.71%）小 1~2 个数量级。§10 / §14 里那些换手 7.6x~18.5x 的读数**不需要因冲击成本打折**。
2. **容量量级 2~7.5 亿**：未成交 ≤1% 对应 2.0~3.6 亿（5% 参与率），≤5% 对应 3.6~7.5 亿。
   到那时才是真障碍 —— 现在不是。
3. **最紧的是 alpha144，不是换手最高的 alpha015**：alpha144 换手最低（7.6x 双边）却容量最小
   （2.01 亿，1% 参与率下未成交 10.66%），根因是它累计成交额最小（225 亿 vs a042 的 407 亿）
   —— 它挑的是低成交额小盘股。**「换手低」不等于「容量大」**。
4. **逐年无一年是障碍**：2018~2020 最难（0.36%~0.59% @5%），2015 反而小（当年成交额巨大），
   没有任何一年超过 0.6%。
5. **缺 amount 的成交笔数 37~202 笔（占笔数 0.02%~0.14%）**，已按口径 1 单列报出；多为停牌/
   退市强平的 0 价成交。
6. **偏置方向（引用时必须带）**：这是**偏乐观的下界** —— 分母只含已成交笔数（被涨跌停挡掉的真成本没进来），
   且未算顺延到次日的价格损失。所以它只能否决「冲击成本是当前障碍」，不能证明「实盘一定成交”。

→ 由此，后续推进「组合骨架 / 市值中性化」无需先解决流动性；两者仍只能当**披露**，不得当筛选判据。
