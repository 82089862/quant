## 0. 结论（先结论）

**不能证明合规。既有原文不足以裁决 —— 按用户要求：停止并报告。**

三条判定句：

1. **停手期原文只禁「新增防线」，全文没有给「防线」下定义** —— 是「写进 §6 五环节流水线的闸」，还是「任何新增的淘汰门槛」，两种读法对本次操作给出**相反**结论。原文无法裁决。
2. **本次操作不属于停手期原文允许的两类去向。** §0 规则 3 只写「精力转**原料/出口**」，而给一个已有候选写判据协议**既不是原料、也不是出口** —— 是第三条路，原文未覆盖。
3. **最接近的一条具体先例对本次操作不利。** `Alpha191候选分层回测计划.md` §14 / §14.2 明确写过：把**已看过的读数**升级为**判据** = 新增防线，须「另立防线卡 + 等停手期结束」。R1–R4 正是把读数升级为判据。

⇒ 判据协议**继续停在草案状态**，不进执行阶段。

## 3. 必须报告的三个歧义/问题

### 3.1 关键词「防线」无定义（核心歧义）

- **读法 A（严格）**：防线 = 任何新增的淘汰/纳入门槛 ⇒ R1 三段同号、R3 的 k、R4 的保留比例都是新门槛 ⇒ **撞停手期**。
- **读法 B（宽松）**：防线 = 写进 `研究方法与验证协议.md` §6 五环节的通用闸；只作用于单一候选、不复用、不进流水线 ⇒ **不撞**。
- **原文无法区分 A / B。** 判据协议 §6 自列的 4 条条件（只作用一个候选 / 不写流水线 / 不改在册状态 / 不被复用）在既有协议中**找不到出处** —— 属**自定判据**。

### 3.2 判据协议 §6 的日期引用不精确

判据协议 §6 写「停手期至 **2027-04-11** 禁止新增防线（`假设登记表.md` §0 规则 3）」。核对：**§0 规则 3 原文里没有 2027-04-11 这个日期** —— 该日期出自 `假设登记表.md` **§6 动作计数**（触发日 2026-10-11 + 半年 = 2027-04-11）。**结论不变，但引用应改为 §6。**

### 3.3 与「规则 2」的交叉（比停手期更硬，且不需要裁决定义）

`假设登记表.md` §0 规则 2 原文：

> **死因码同码即停。** 新假设失败后归档死因码，若与已有码相同（查 `../死因码表.md`，含电力域）→ 判为重复投入，立即停止，**不许再加防线**。
