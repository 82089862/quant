# 基本面数据源计划（换数据，不换因子）

> 建立 2026-10-15。**状态：第 0 步未开始（骨架 + §11 四条决定已拍板）。**
> §11 的四条分歧于 2026-10-15 由用户授权 agent 决定；其中**决定 1 直接淘汰了初稿机制**，已留痕不改写。
> 判法与局限见 `../研究方法与验证协议.md`；失败原因见 `../死因码表.md`；
> 假设卡写 `假设登记表.md`（H 号）；任务完成情况不在本文件，见 `未做工作清单.md`。
> **本计划是漏斗，不是步骤表**：任一步的终止条件触发即立刻结束，不进入下一步。

## 1. 要解决什么

**一句话**：项目至今 **147 个因子全部是价量**，价量数据的信息容量已经饱和
（23 个派生特征，有效维度 PR 7.32；协议 §1.4 结论 =「冗余是全局低秩，D 饱和后
继续做特征工程不再增加信息，**只有换数据或换目标才有用**」）。

**本计划换的是数据，不是因子**：引入**财务报表数据**（应计 / 盈余意外 / 质量），
按现有五环节走一遍，判断它是否构成价量基之外的新维度。

**为什么不做"再找几个价量因子"**：`capacity.py` 的判据已经写死 —— 新想法先投影到
既有基上算 R²，**> 0.95 直接扔**。价量空间里能加的东西已经被 147 次尝试覆盖。

## 2. 前置闸门：机制行（写不出 / 审不过 → 计划终止）

`假设登记表.md` §0 规则 1：**没有「机制」行的假设，不许进验证脚本。**
机制 = 谁在被迫以错误价格交易、他为什么改不了。

### 2.1 初稿表述已被自己判不合格（留痕）

初稿写的是「投资者对会计信息反应滞后（散户占比高）+ 卖方覆盖被摊薄，注意力有上限」。

**这不满足 §0 规则 1** —— 它是**认知偏差**，不是"谁在被迫交易"，按规则只算数据挖掘。
判定日 2026-10-15，**留痕，不改写成"事后把偏差说成被迫"**。

### 2.2 改写后的机制（合格版本）

| 项 | 内容 |
|---|---|
| **谁被迫** | **被动 / 指数化资金**。它的合同就是复刻指数，**不能因为基本面恶化而卖出**。注册制后上市标的增至 5,400+，而被动规模已超过主动（指数基金持 A 股市值已破 3.2 万亿），相当一部分个股的边际定价者已从"主动研究者"换成"被迫按权重持有的被动资金" |
| **为什么改不了** | 跟踪误差是硬约束，管理人**无权**因基本面判断偏离权重。**这是合同层面的约束，不是意愿问题** |
| **痕迹** | 基本面信息（尤其是否定信息）进不了价格 → 应计 / 盈余意外类指标对次月截面收益有**同向**预测力，且**剔除价量控制集后仍存在** |
| **额外的自洽检查**（只作描述，不作判据） | 若机制成立，信号应**集中在「主动覆盖低 + 被动占比高」的股票上**。这是本机制**自带的一个可证伪方向**，比只报一个总 IC 强 |
| **证伪判据** | 见 §6（跑之前冻结） |

### 2.3 仍需审阅者判定的一点

改写后的机制把责任放在**被动资金的合同约束**上。
若审阅者判定"被动资金按权重持有不算被迫以错误价格交易"，则本计划**终止**，不进第 0 步。

## 4. 漏斗：六步，每步都有终止条件

**这是本计划的形状。任何一步的终止条件触发，立刻结束，不写"再来一次"。**

| 步 | 做什么 | 成本 | **终止条件（触发即结束）** | 对应死因码 |
|---|---|---|---|---|
| **0** | **数据可得性实测**：baostock 财务接口能否拉到、历史深度、**退市股覆盖** | 半天 | 拉不到 / 历史不足 2015 起 / 退市股缺失（幸存者偏差） | — |
| **1** | **判重**：候选财务特征投影到现有 23 维价格主成分基，算 R² 与 **PR 净增** | 半天 | **PR 净增 < +0.5**（协议 §2.2 判据：+0.1 以内是同族数据）**或** R² 高（价格已隐含） | — |
| **2** | **裸 IC 是否过 KILL 线**：月频截面 rank IC | 1 天 | **\|IC\| < 0.0141**（KILL = 0.0704/5，**不自造阈值**） | **F5** |
| **3** | **正交性阶梯 + 控制集 2¹¹ 穷举**（复用 `dominance.py`） | 1 天 | 存在**单个**控制变量就把 \|残差 IC\| 打到 KILL 线下 → 确凿换皮 | **F3** |
| **4** | **surrogate 噪声底 + 训练/测试切分**（复用 `alpha191_surrogate.py` 的置换侧） | 1 天 | 不过噪声底 **或** 样本外归零 | **F2 / F1** |
| **5** | **分层回测 + 判据②③④**（复用 `factors.run_layers` + `layer_judge.py`） | 1 天 | 年化跑不过反转基线 **7.60%**，或 4 条判据任一不过 | — |
| **6** | 仅当前 5 步全过：进组合（阶段⑤）、立 H 卡 | — | — | — |

**漏斗的期望值**：第 0–1 步合计 **1 天**，就能否掉这条路。
参照两融：第 1 步过关了（PR 净增 +1.95），但第 3 步（F3）全灭。

**明确写死（换字段规则，见 §11 决定 4）**：第 1 步不过关时，**允许换字段重开一次，上限 1 次**，且必须同时满足：

1. 换字段的理由必须是「**上一批字段有构造缺陷**」（例如经查是规模代理 / 数据本身不可靠），
   **不能**是"没过关所以换一批试试" —— 后者就是变相调参
2. 重开必须在 §12 状态表**留痕**（日期、换掉了什么、为什么）

第二次仍不过关 → **计划终止，不开第三次**。

## 8. 验收与对账

- 第 1 步：`capacity.py` 的 R² / PR 净增必须与手工重算一致（自检断言）
- 第 2 步：`ic_nocontrol` 必须与 `factors.ic_series` 的测试段 IC **逐位相等**，不等即 raise（沿用 `alpha191.py` 的对账闸）
- 第 3 步：全量控制集（k=11）的残差 IC 与 R² 必须与 `margin_factor.py` 逐因子一致（差 < 1e-9）
- 每步产物落 `stocks/out/`，命名带 `fundamental_` 前缀，**不与冻结产物同名**

## 9. 已知坑

1. **财务数据与规模高度共线** → 第 1 步就可能给出**假的过关**。见 §10 第 1 条。
2. **幸存者偏差**：退市股财务数据可能缺失。项目已踩过（退市归零使反转 G5 掉 36%）——
   **实测影响：组合收益型判据对退市股极敏感，截面 IC 型几乎不敏感**（协议 §9）。
3. **季度低频 + 月频调仓**：信号更新慢、换手低，但可能已被市场充分消化。
4. **财务数据会重述**（追溯调整）→ 只用公告当时可知的值，否则是前视。
5. **数值链路的钉子**：要与归档产物对账的脚本**不许钉 DuckDB `memory_limit`**（协议 §11.4 七.2）。

## 10. 不在本计划内（第一版）

1. **不放规模代理字段**（ROE、总资产、净利润绝对额、市值类）—— 测出来必然是 **F3**。
   只放**相对量**。第一批字段清单见 §11 决定 3（四个，全部无量纲）。
2. **不做财报公告日的事件研究** —— 撞协议 §12.3（事件驱动 → 样本稀疏 → 必然 F1 全灭）。
3. **不做参数搜索 / 调参** —— 靠执行或参数取胜的策略在本流程里既过不了关也证不了伪（§12.4）。
4. **不新增任何防线**（停手期）。
5. **不做指数成分 / 解禁 / 被动持股** —— 三条备选线各自另立计划，不塞进本计划（防止"这条没过换那条"的滑移）。
