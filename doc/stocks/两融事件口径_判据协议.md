## 0. 为什么先写规则，再跑数

三条**已固定**的事实：

1. **全样本均值优势存在，但不普遍。** 均值差 +0.3315pp，中位差 **−0.22pp** —— 均值与中位数方向相反，不能只引用前者。
2. **2015 影响很大，但不能据此认定其余年份无信号。** 2015 贡献 51.1%；其余年份均值差仍为正，但只有 **+0.18pp**，而纯费用往返已是 **0.102pp**。
3. **当前缺的是判定规则，不是更多描述性统计。** 年度数据已落盘、报告错误已更正；继续重复均值 / 中位数 / 年度贡献，不会自动产生可信的退出结论。

**本协议不可违反的四条原则**

| # | 原则 |
|---|---|
| **P1** | 规则**先冻结**，跑数后不许改。事后调一次 = 本协议作废 |
| **P2** | 以**量级判据**为主，不用 p 值（停手期允许；且项目已实测显著性在此类候选上无判别力） |
| **P3** | 每条规则必须写明**误杀风险**。写不出误杀风险的规则，不予采纳 |
| **P4** | 每条规则**可独立判死**；但**不能单独判「保留」** —— 保留须全部通过 |

## 1. 四条规则

### R1 时间稳健性 —— 区分「跨时期可重复」与「单一年份主导」

| 项 | 内容 |
|---|---|
| **目的** | 不让单一年份的极端读数冒充跨时期规律 |
| **候选形式** | **a. 分段同号**：固定三段 `2015-2016` / `2017-2020` / `2021-2026`，每段 `exec5` 均值差 > 0<br>**b. 集中度上限**：单一年份对全样本均值差的贡献 ≤ X%<br>**c. 剔除最大贡献年**：剔除 2015 后仍 > 0 |
| **阈值依据** | 现有锚点只有一个：2015 = **51.1%**。X 取多少**没有现成依据**，属自造 → 若采用 b，必须由用户给定 X 及其理由 |
| **误杀风险（最关键）** | **强平事件的机制本身就预测集中在暴跌年份** —— 强平潮发生在极端下跌期，所以「时间集中」可能是**机制的预期特征，而不是缺陷**。用 b（集中度上限）会**系统性杀掉所有事件驱动型的真实信号** |
| **建议 → 拍板** | **2026-10-16 批准：只用 a（分段同号）作为候选门槛**，三段 `2015-2016` / `2017-2020` / `2021-2026` 各自报事件组与对照组收益差；**b / c 降级为披露读数，不单独判死**。注意：分段同号**不是充分条件** —— 某段为正可能来自少量极端观测 → **必须与 R2 联合解释，不得把三段同号直接等同于稳定有效** |
| **所需数据** | **零新增** —— `out/margin_event_yearly.csv` + `out/margin_event_periods.csv` 已够（注意：现有时期划分是二段，三段需重跑一次分组） |

### R2 分布稳健性 —— 均值优势是否只由少数极端收益造成

**先澄清一件决定本规则形态的事**

> **单笔观测的中位数 ≠ 组合收益的中位数。**
> **N 只等权组合的收益趋近单笔的均值，不是单笔的中位数。**
> 因此「单笔中位数为负」**不能**直接推出「策略不可交易」—— 那是把**单笔分布**的诊断当成**组合层面**的结论。

| 项 | 内容 |
|---|---|
| **目的** | 判断纸面均值优势是否由右尾少数观测撑起，以及它是否能在组合层面实现 |
| **候选形式** | **a. 修剪均值**：剔除最大 1% / 5% 观测后均值差仍 > 0<br>**b. 组合层面**：事件样本按日组成等权篮子，看**篮子收益**的胜率与中位<br>**c. 效应量**：均值差 ÷ 单笔收益标准差<br>**d. 单笔中位数方向** —— **仅披露，不作判死**（理由见 §3） |
| **阈值依据** | a 里取 1% 还是 5%、b 里胜率门槛取多少，**均无现成依据** → 待用户拍板或改用 c 的相对比较 |
| **误杀风险** | **流动性补偿 / 被迫抛售类机制本来就是尾部机制** —— 本项目 H11（`alpha144`）的机制原文正是「下跌日被迫抛售的流动性提供者获得补偿」。用 a 或 d 判死，会杀掉**同类真实信号** |
| **所需数据** | 需新计算（a / b / c），**不需要新数据源** |
| **拍板** | **2026-10-16 批准：单笔分布与组合分布都报；只有组合层面可用于判死**（单笔分布仅作机制诊断）。**修剪均值 / 篮子胜率暂不设硬阈值**，只报数 |

### R3 经济价值 —— 扣费后还值得继续吗

**前置（不给就先跑，等于没有分母）**

1. **组合定义**：N 只等权 / 持 5 日 / 资金规模 / 参与率
2. **成本口径**：费率（沿用 `backtest.py` 默认 = 往返 **0.102pp**）+ 滑点（沿用 `impact_check.py` 的静态参与率口径）
3. **调仓节奏**：事件驱动是每日建仓，还是按事件日分批

| 项 | 内容 |
|---|---|
| **候选判据** | 净优势 > 0 **且** `净优势 ÷ 总成本 ≥ k` |
| **阈值依据** | **k 无现成依据。** 项目可参照的锚点：① 反转基线 G5 年化 **7.60%**（判据①的线）；② `impact_check.py` 的容量线（未成交 ≤ 1%）。**建议 k = 2，但必须由用户拍板**，并强制同时报告 k = 1 的读数以暴露敏感性 |
| **误杀风险** | k 定太高 → 杀掉真实但薄的信号；定太低 → 等于没闸 |
| **所需数据** | 需新计算（组合层）+ **需用户先冻结组合定义** |
| **拍板** | **2026-10-16：先提交组合定义 → 批准后冻结**（须明确标的数 / 持仓期 / 资金规模 / 参与率 / 建仓与重叠规则 / 费用口径），提案见 `两融事件口径_组合定义提案.md`。**k=2 暂不冻结**：k=1 与 k=2 **同时报告**，在给出经济依据（总成本含哪些项、成本估计的不确定性、为何两倍成本足以覆盖）之前，**任一数值都不得作为正式判死门槛** |

### R4 可执行性 —— 哪些涨跌停 / 停牌 / 容量问题足以让纸面收益失去意义

| 项 | 内容 |
|---|---|
| **候选判据** | **a.** 剔除 T+1 一字跌停 / 停牌样本后，均值差保留比例 ≥ 阈值<br>**b.** **必须同时报告被剔除样本的收益** —— 若被剔除样本收益更低，说明策略依赖**买不到的东西**（方向诊断，比阈值本身更有信息）<br>**c.** 容量：按 `impact_check.py` 口径，1 亿 / 5% 参与率下未成交占比 ≤ 1% |
| **阈值依据** | c **沿用项目已冻结口径**（`Alpha191候选分层回测计划.md` §15）；a 的阈值**无现成依据** → 待定 |
| **误杀风险** | a 过严 → 杀掉真实但集中在易封板标的上的信号；不设 → 把买不到的价格当作真实收益。b 是唯一能判断方向的读数，**不可省略** |
| **所需数据** | 需新计算 + **接线两个已有零件**：`backtest.price_limit_pct` + OHLC 判一字板；`impact_check.py` |

## 3. 关于「中位数必须非负且优于对照组」—— 为什么不建议硬化

**事实**：`研究方法与验证协议.md` / `死因码表.md` / `假设登记表.md` 全文检索**没有**这条规则（见 `阶段性报告.md` §8.3）。它是**看到结果之后**才提出的 → 属**新规则**。

**若硬化，必须先回答它服务什么目标**：

| 若目标是 | 那么 | 判定 |
|---|---|---|
| 判断分布是否右尾驱动 | 它只是 R2 的一个**读数** | 不足以判死 |
| 判断是否可交易 | **论据不成立** —— N 只等权组合的收益趋近单笔**均值**，不是单笔中位数 | 不能作判死依据 |

**三种定位（按性价比排序）**

1. **披露读数**（不作判死）—— 最省，且保留全部信息
2. **改为组合层面**：篮子收益的中位数 / 胜率 —— 更贴合「可交易性」这个目标
3. **硬门槛** —— **不建议**：那等于从「追逐均值优势」改成「追逐中位数优势」，**仍然是看过结果之后换尺子**

> 用户原话已写入本协议：**「不要直接把『中位数必须非负且优于对照组』变成硬门槛」**。

## 5. 退出状态：三类，不是两类

| 状态 | 含义 | 交付要求 |
|---|---|---|
| **判死** | 按已冻结规则判定净价值不足 / 分布不稳 / 时间不稳 | 必须写明触发的是哪一条、哪一档、哪个读数 |
| **无法判定** | 证据不足 | **必须是合法退出状态** —— 不得强行归入「判死」或「保留」 |
| **保留** | 全部规则通过 | 仍只能标「研究数据（非独立验证）」（协议 §9.1） |

> 依据：用户已定的三分法，以及项目原则 **「发现失败模式，不等于必须把所有可疑现象都立即变成否决规则」**。
