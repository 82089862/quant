## 1. 使用契约

1. 每行一个任务，格式：`- [ ] **<短名>** —— <一句话做什么>（来源：<哪个文件/哪一步>）`。
2. `来源` 必须指向**已存在的文件**或本清单内的上游任务，不许写「想法」。
3. 新增任务前先搜本文件，同义任务**合并**不新增。
4. 任务完成 → 删行 + README §进度 记一行。**不许标 `[x]`**（留成堆已完成项等于第二份 README §进度）。
5. 本文件不写判据、不写死因码 —— 那些在 `../研究方法与验证协议.md` 与 `../死因码表.md`。
