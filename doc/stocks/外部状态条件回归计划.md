## 1. 要解决什么

### 1.1 问题

市场状态变化有真实的外部环境成因（利率路径、美元流动性、持仓拥挤度、全球工业实需）。要问的是：**这些外部状态能否解释因子的失效**。

### 1.2 为什么不用「商品价格暴跌事件」当因变量（实测）

原设想是「标记价格暴跌 → 归因外部状态 → 存进死因库」。实测各标的**可得全历史**的 ≥30% 非重叠下跌腿（zigzag，交替 20% 反转判定）：

| 标的 | 可得区间 | ≥30% 下跌腿 | 训练半段 / 测试半段 |
|---|---|---|---|
| WTI 原油 `CL` | 1996-10 ~ 2026-10 | 17 | 8 / 9 |
| COMEX 铜 `HG` | 2016-10 ~ 2026-10 | 2 | 1 / 1 |
| **COMEX 黄金 `GC`** | 2016-10 ~ 2026-10 | **0** | 0 / 0 |
| COMEX 白银 `SI` | 2016-10 ~ 2026-10 | 4 | 1 / 3 |
| 天然气 `NG` | 2016-10 ~ 2026-10 | 16 | 5 / 11 |

两条结论：

1. **价格事件不是收敛的数据点**。铜 1 个训练样本、黄金 0 个；黄金最有名的失效诱因（2013 taper tantrum，约 −45%）整个在免费窗口之外。n≤17 还要再切训练/测试，任何判据都必然落在 F1 / F2 上。
2. **事件计数本身不可靠**：WTI 的 36 条 ≥20% 腿里 3 条挤在 2020-04，多条 20~25% 是波动聚集噪声；可识别的独立危机约 5~6 个（1998 / 2001 / 2008 / 2014-16 / 2020）。

### 1.3 改用什么

**因变量换成因子逐月 IC 序列**（n≈141，已在磁盘上），外部状态当自变量：

```
IC_t  ~  a + b · regime_t + e            t = 1..N（月）
```

- n 从 ≤17 提到 ≈141，且 §3 的横截面判据仍然有效（A 股是横截面，regime 是时间维）。
- 复用现成的训练/测试切分口径（`alpha191.py --split`，默认 `2020-12-31`）。
- F1 / F2 / F4 三条死因码全部可用。

**本仓已有先例**：`stocks/out/margin_factor_ic_series.csv` 就是逐期 IC 序列落盘；`stocks/factors.py:ic_series()` 是唯一定义处。

## 3. 前置闸门：H12 机制行（**执行第 0 步登记**）

```
### H12 外部宏观状态（利率 / 流动性 / 持仓拥挤）对因子 IC 的条件回归

假设: 因子 IC 的高低受同时点外部宏观状态（美债期限利差、美债 10Y 变化、CFTC 美元投机净持仓、LME 铜注销仓单占比、WTI 月收益、铜金比变化）条件影响，该影响在训练段与测试段符号一致

死因码: -
```

## 5. 事先判据（写死在跑之前）

### 5.1 自变量（6 个）

`stocks/fetch_regime.py` 的 `SPEC` 是唯一 provenance，随代码进 git：

| 列名 | 接口 → 字段 | lag_days | 月频口径 |
|---|---|---|---|
| `cftc_usd_net` | `macro_usa_cftc_nc_holding` → `美元-净仓位` | 3 | 月末快照（投机拥挤度） |
| `lme_cu_cancel_ratio` | `macro_euro_lme_stock` → `铜-注销仓单` / `铜-库存` | 1 | 月末快照（实需紧张度） |
| `us_10y2y` | `bond_zh_us_rate` → `美国国债收益率10年-2年` | 0 | 月末快照（衰退预期） |
| `us_10y_chg` | `bond_zh_us_rate` → `美国国债收益率10年` | 0 | 月末环比变化（贴现率冲击） |
| `wti_ret` | `futures_foreign_hist('CL')` | 0 | 月收益（成本冲击） |
| `cu_au_ratio_chg` | `HG` / `GC` | 0 | 月末环比变化（风险偏好） |

**lag 实现**：`series.asof(month_end - Timedelta(days=lag_days))`。`asof` 天然只取「该时点及之前」的最后一条，无前视。
**禁止**：先按月末聚合再 shift —— 那会把月末之后公布的数据算进来。

### 5.2 因变量（14 个）

13 个候选（实测读自 `out/alpha191_ic.csv`，`verdict=部分独立` 且 `bonferroni=1` 且 `sign_same=1`）：

```
alpha015 alpha035 alpha042 alpha070 alpha078 alpha081 alpha088
alpha107 alpha135 alpha139 alpha144 alpha164 alpha184
```

**加基线 `reversal20` = 14 个。理由（见 §8.4）**：它同时充当**方法校准项**——README 已记录它分年不稳（2016/2017/2018 连负、2025 +39.4%），是唯一有独立先验的因子。若回归在它上面也测不出任何东西，读数只能说明「方法在这批状态上没有功效」，而不是「因子都健康」。输出表加一列 `role`（`基线` / `候选`），基线不计入候选发现。

### 5.3 判据表

| 判定 | 阈值 | 死因码 |
|---|---|---|
| **存活** | p ≤ 0.999405 **且** `b_train`/`b_test` 同号 **且** \|b\| > surrogate 95 分位 | — |
| 未过多重检验 | p > 0.999405 | `F1` |
| 样本外归零 | 训练显著（p_tr < 0.05）但测试 `\|t_te\| < 1` | `F2` |
| 跨期符号相反 | `sign(b_train) ≠ sign(b_test)` | `F4` |
| 未超噪声底 | \|b_full\| ≤ surrogate 95 分位 | `F5` |

- **检验次数 N = 14 × 6 = 84**，Bonferroni 门槛 `1 − 0.05/84 = 0.999405`。
- **surrogate**：循环平移 `regime` 序列 300 次（保留自相关、破坏与 IC 的真实关系），同套回归得 \|b\| 噪声分布 → 取 95 分位。方法同 `stocks/timing.py` / `stocks/leadlag.py`。
- **不套用量级线 KILL = 0.0141**：那是 **IC 口径**的量级线；本计划判据对象是回归斜率 `b`（IC per regime 单位），量纲不同，不可比。现量级用 surrogate 噪声底替代。

### 5.4 训练 / 测试切分

`2020-12-31`（该日含在训练段），与 `stocks/alpha191.py --split` 默认值一致，**不另立口径**。

## 7. 已知坑

1. **LME 库存止于 2026-07-17**。`asof` 会静默 ffill 到 10 月，外推 3 个月。必须显式断言「最后真实观测日 ≥ 检验窗口末端 − 5 天」，否则测试段偷偷少 3 期且不外显。
2. **`cu_au_ratio` 只有 10 年历史**（`HG`/`GC` 均 2016-10 起），而其余 5 个自变量覆盖更长。若与 IC 序列的重叠月数不足 130，84 次检验的等样本前提被破坏 → 第 2 步验收时决定**截齐**还是**分列报告**。
3. **`bond_zh_us_rate` 打 19 个子请求**（实测带进度条约 3 s）。一次性拉全后本地切片，**不要按变量重复调**。
4. **预期存活数可能是 0**。84 次检验 × 门槛 0.999405 很严。按协议 §12.4 这是设计取舍（宁可错杀），不是故障。读数前先把这句话写进结果。
5. **`--only 13` 下 `gate()` 会把 Bonferroni 按 13 次算**（而非 147 次）。本计划只取 `ic_series` 列、不读该列，无影响 —— 但第 1 步验收要确认它确实没报错。
6. **并发写手**：本仓有多个 agent 会话同时操作同一工作目录（已实测时间线）。动手前 `git log --oneline -3`，提交时**显式列文件**，不用 `git add -A`。
7. **`alpha191_ic_series.csv` 会被全量跑覆盖**。「147 个全跑」版本写同名文件 → 若将来跑全量，需先备份或改名。列为待做清单条目。
