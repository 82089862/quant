## 给 agent 的读写契约

写任何东西之前先读完本节。

1. **记录块是原子单位**：一个假设 = 一个 `### <ID> <标题>` 块，块内是固定的 `键: 值` 行。
2. **只追加，不改旧块**。唯一例外是状态流转（改 `状态` 行）和补齐当初空着的字段。
3. **追加位置**：写到 `<!-- APPEND-HERE -->` 这一行的**上方**。
4. **ID 规则**：本域用 `H1, H2, H3...` 单调递增，删除后**不复用**（与死因码同规则）。取下一个 ID 用 `rg -o '^### H[0-9]+' doc/stocks/假设登记表.md | sort -V | tail -1`。
   全域 ID 前缀分配：`stocks` = `H`，`power` = `P`。两域不共用序列，因此永不撞号。
5. **键名不许改、不许加、不许删**（下面 §1 是全集）。缺内容写 `-`，不许省略整行。
6. **每个值单行**，不许出现 `|`；需要换行用 `<br>`。
7. **`状态` 只许取**：`待验证` / `验证中` / `通过` / `失败` / `作废`。
8. **失败必须填 `死因码`**，且必须先查重：查 `../死因码表.md`，若该码已存在 ≥1 个案例（**含电力域的案例**），按 §0 规则 2 **立即停止投入**，并在 `结果` 里写明「重复投入，已按规则 2 停手」。

## 0. 三条硬规则

1. **没有「机制」行的假设，不许进验证脚本。** 机制 = 谁在被迫以错误价格交易、他为什么改不了。写不出 = 不是假设，是数据挖掘。
2. **死因码同码即停。** 新假设失败后归档死因码，若与已有码相同（查 `../死因码表.md`，含电力域）→ 判为重复投入，立即停止，**不许再加防线**。
3. **每季度末统计动作分类，筛子类 > 50% 即触发停手**（半年内禁止新增防线，精力转原料/出口）。

## 1. 记录块格式（字段全集）

| 键 | 必填 | 取值 |
|---|---|---|
| `假设` | 是 | 一句话，可证伪 |
| `机制` | 是 | 谁在被迫以错误价格交易，他为什么改不了 |
| `痕迹` | 是 | 应该在哪个可观测统计量上留痕，符号方向是什么 |
| `证伪判据` | 是 | 事先写死的量级线 + 控制集（固定 k=11 全集，不许事后挑控制集） |
| `预算` | 是 | 时间 X 天 / 算力 Y / 到 Z 号不通过就扔 |
| `状态` | 是 | 五选一（见契约第 7 条） |
| `日期` | 是 | 建卡日 `YYYY-MM-DD` |
| `结果` | 否 | 验证后在册的结论，写清量级与方向 |
| `死因码` | 失败必填 | `F1`~`F5`（见 `../死因码表.md`）；未失败写 `-`。多个码写**多行**（`死因码: F1` / `死因码: F2`，一行一个），否则 §8 统计会漏 |
| `证据` | 否 | 脚本名 + 关键数字，供回溯 |

## 7. 维护规则

- 假设进验证前先有记录块；块内缺 `机制` 值的，不许进验证脚本（§0 规则 1）。
- 死因码只在 `../死因码表.md` 增改，**本文件不复制码表**；删码在那边把 `状态` 改 `已废弃` 并写明理由。
- 每次失败归档后**立刻**查重（`../死因码表.md`，含电力域），同码 → 停止投入。
- **建卡时把「当时的怀疑」一并抄进卡**：事前判断必须落在卡里，不能只留在可原地修订的计划文档里（例：H11 建卡前 `Alpha191候选分层回测计划.md` §2 曾把 a144 机制标「⚠ 弱」，理由已抄入 H11）。后续信心变化**追加**到 `结果`、带日期，**不改写旧判断** —— 这是「只追加，不改旧块」在判断上的形态。
- 每季度末更新 §6，统计筛子 / 原料 / 出口比例。
- 改本文件的字段口径时，同步改 `../研究方法与验证协议.md`（两者冲突时以那个文件为准，本文件只加流程）。
