# 假设登记表

> 目的：把「失败收敛」从安慰变成**查重器**，把「提问」从目标式变成决策式。
> 建立 2026-10-11。与 `doc/研究方法与验证协议.md` 配套：那个文件管**怎么判**，这个文件管**从哪来、值不值得判、通过后怎么办**。

## 0. 三条硬规则

1. **没有「机制」行的假设卡，不许进验证脚本。** 机制 = 谁在被迫以错误价格交易、他为什么改不了。写不出 = 不是假设，是数据挖掘。
2. **死因码同码即停。** 新假设失败后归档死因码，若与已有码相同 → 判为重复投入，立即停止，**不许再加防线**。
3. **每季度末统计动作分类，筛子类 > 50% 即触发停手**（半年内禁止新增防线，精力转原料/出口）。

## 1. 假设卡（进验证前必须填满 5 行）

```
假设：
机制：      谁在被迫以错误价格交易，他为什么改不了
痕迹：      应该在哪个可观测统计量上留痕，符号方向是什么
证伪判据：  事先写死的量级线 + 控制集（固定 k=11 全集，不许事后挑控制集）
预算：      时间 X 天 / 算力 Y / 到 Z 号不通过就扔
```

示例（唯一一个写得出机制的、还没做的方向；**数值与判据都是示意，未验证**）：

```
假设：      指数期权隐含波动率与已实现波动率之差（VRP）有可预测结构
机制：      做市商与对冲盘被动买入波动率保护，系统性高估尾部风险；散户无法做空波动率
痕迹：      IV 与 RV 之差在暴跌后 1 个月内有正偏、在平静期转负
证伪判据：  市场级口径（不是个股截面）：VRP 对次月指数收益的样本外 IC 符号一致且 |IC| ≥ 0.05
预算：      接入 5 天（akshare 免费接口）/ 到 2026-11-01 不通过就扔
```

注意：IV / 基差是**市场级**信号，不能当个股因子用（见 doc §11.1 的 S 层说明）。

## 7. 维护规则

- 假设进验证前先有卡；没有机制行的卡不许进 `dominance.py`。
- 死因码只增不改；删码必须在 §3 留一行划掉的痕迹并写明理由。
- 每次失败归档后**立刻**查重（§3），同码 → 停止投入。
- 每季度末更新 §6，统计筛子 / 原料 / 出口比例。
- 改本文件 = 改 `doc/研究方法与验证协议.md` 的口径时同步改（两者冲突时以那个文件为准，本文件只加流程）。
