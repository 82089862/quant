## 2. 自然人入市是**两段式**，不是一步

关键认知：**并网和市场注册是两个地方办的事。** 并网找电网企业（国网新疆电力），市场注册找交易机构（新疆电力交易中心）。先有电源并网、拿到备案和计量，才能注册为经营主体。

### 第 1 段：分布式光伏并网（找国网，不在交易中心）

- **渠道**：**「网上国网」APP** 或当地**供电营业厅**
- **自然人户用流程**（4 步）：并网意向受理及回复 → 现场勘查 → 接入系统工程建设 → 并网检验
- **自然人户用需提交**：
  - 申请人**有效身份证明**原件（身份证 / 军人证 / 护照 / 户口簿 / 公安机关户籍证明）
  - **发电地址权属**证明（房屋产权所有证 / 土地证 / 宅基地证 / 乡镇及村证明）
- ⚠ 以上流程与材料取自国网对外发布的《分布式光伏并网业务办理告知书（自然人户用）》，**新疆本地版本的具体要求需向当地供电营业厅核对**（各地在可并网区域划分、容量上限上有差异）

### 第 2 段：市场注册（新疆电力交易中心）

**基本条件**（✅ 《电力市场注册基本规则》国能发监管规〔2024〕76 号 **第十三条** 分布式电源经营主体）：

1. 依法取得**发电项目核准或者备案文件**
2. 与电网企业签订**负荷确认协议或并网调度协议**，按电压等级标准接入新型电力负荷管理系统或电力调度自动化系统
3. 具备相应的**计量能力**或者替代技术手段，满足电力市场计量和结算的要求

**主体资格**（✅ 同规则 **第七条**）：个体工商户、**执行工商业电价或具有分布式电源的自然人**等民事主体，提供有效身份证明证件及相关注册材料即可办理。

**流程**（✅ 第十八~二十一条）：

```
申请 → 承诺 → 审查 → 公示 → 生效
```

| 环节 | 规则 |
|---|---|
| 提交 | 身份认证、联系方式等信息 + 支撑性材料，**签订入市协议** |
| 审查 | 交易机构 **5 个工作日**内审查，必要时现场核验；材料不符**一次性告知** |
| **公示** | **分布式电源原则上无需公示，注册手续直接生效**（第二十条）← 这是最省事的一点 |
| 生效后 | 纳入经营主体目录，按信息披露要求向社会公布；向能源局派出机构与地方政府主管部门备案 |

**一地注册、各方共享**（✅ 第四条（四））：可自主选择电力交易机构办理，无需重复注册。

### 第 3 段：参与市场

✅ 新疆指引 5.0 第十三条：参与中长期市场的**分布式光伏**参与现货市场，具备条件的**可按月自主选择**「报量报价」或「报量不报价」；不具备条件的「不报量不报价」，作市场价格接受者。

## 3. 登录平台后要确认什么（勾选清单）

按对建模影响的优先级排序。

### A. 决定能不能做（先问这几条）

- [ ] **A1 分布式电源 / 自然人注册入口是否存在**。新疆已发布分主体服务指南：发电企业（2023 征求意见）、**独立储能（2025 年修订版，2025-09-30）**、**零碳园区内经营主体（2026-07-21）**。要确认有没有独立的「分布式电源」或「自然人」指南，还是并入发电企业指南办理。
- [ ] **A2 户用光伏的容量门槛**。有无最小容量、最低电压等级要求（10kV 以下能否注册）。
- [ ] **A3 计量硬要求**。是否强制 96 点曲线计量装置；户用表是否满足（不符合则只能用「不报量不报价」，那就没有报价可优化）。
- [ ] **A4「具备条件」由谁判定**。「可按月自主选择报量报价」的「具备条件」标准，条文里没写，问清楚判定方和申请方式。

### B. 决定模型能不能校准（关键）

- [ ] **B1 信息披露专区的实际粒度**：出清价是**节点电价**还是只给**统一结算点**？96 点还是小时？
- [ ] **B2 历史回溯长度**：能看到多久以前的出清价格与负荷？只有近期还是可回溯数年？
- [ ] **B3 现货日报系统**（2025-05 投运，「一键生成」）的可见范围：仅发电侧主体，还是所有注册主体都能看？
- [ ] **B4 数据接口**：指引第十二条（五）承诺交易机构「制定信息披露标准格式，**及时开放数据接口**」，结算部分第三条（一）要求结算明细「采用**数据接口**等便于经营主体使用的方式」。**问实际开放形式**：API / 文件下载 / 仅页面；鉴权方式；频率；是否收费。
- [ ] **B5 中长期数据**：96 点中长期电量曲线是否可见（对应指引第二十六条的 24 时段→96 点均分）。

### C. 决定收益算得对不对

- [ ] **C1 阻塞平衡费用**的实际返还数据是否可见（发电侧节点价 vs 用户侧统一结算点价的差额）。
- [ ] **C2 火电成本补偿**现阶段「只统计不结算」（指引第七十条）——确认起始实施时点，这直接影响收益口径。
- [ ] **C3 疆内燃煤基准价**的具体数值（关系到事后市场力参考价 C = 基准价 × 1.5）。
- [ ] **C4 本期**有哪些参数已按期调整（R1~R4、K1~K3、γ、α、β、M 都在规则里写明「适时调整」）。

### D. 顺手核对规格表的 3 处 ⚠（用**官方原文**，不要用转写件）

- [ ] **D1 第七十二条**（煤电运行补偿公式）的出力下限项——转写件里公式符号错行，需原文确认「灵活性改造下限 / 申报下限」如何进入公式。
- [ ] **D2 第三十七条**（独立储能报量报价）报价单位写作「元/兆瓦」，而附件 1-5 的限价单位是「元/兆瓦时」；确认是否为原文笔误。
- [ ] **D3 第十章风险防控（第九十二~九十八条）、第十一章市场干预第一节、第十三~十五章**——本次未读，需原文补齐。
