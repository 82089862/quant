# 新疆电力现货：出清与结算规格表

> 建立 2026-10-12。来源：《新疆维吾尔自治区电力现货市场试运行工作指引 5.0 版》**交易部分**（15 章 + 附件 1-1~1-7）与**结算部分**（8 章 + 电量拟合规则附件），2026-09 发布。
> 转写件取自源电社区（yuandian.space），PDF→文本过程中**公式符号有失真**，凡标 ⚠ 处须回原文核对后再用。
> 用途：`power/` 域建模的规格输入。本文件只记事实，不做解释。

## 0. 一句话骨架

**日前 SCUC+SCED 出清 → 15 分钟节点电价 → 小时内 4 点算术平均成小时价 → 日清月结。**
发电侧按所在**节点**小时均价结算；用电侧按**统一结算点**小时均价结算；中长期按「合约价 − 用户侧日前统一结算点价」差价结算。

## 1. 品种与参与方式（第十三条、第十四条、第十五条）

| 主体 | 参与方式 |
|---|---|
| 公用火电（省调及以上调管） | **报量报价** |
| 集中式光伏、风电（含示范/试验/集中式扶贫/特许权） | **报量报价** |
| 分布式光伏（已参与中长期） | 具备条件：**按月自主选**报量报价 或 报量不报价；不具备条件：不报量不报价（价格接受者） |
| 水电、生物质、综合利用（余热余气余压/燃气）、光热 | **报量不报价** |
| 自备电厂、非市场化水电 | 逐步参与 |
| **直流配套火电、新能源** | **暂不参与**新疆现货市场 |
| 售电公司、批发用户、代理购电工商业用户 | **报量不报价** |
| 独立储能 | 现阶段**报量不报价**，逐步转报量报价 |
| 源网荷储一体化、绿电直连 | 按**用户侧**身份参与 |
| 虚拟电厂·电源型 | 报量报价 |
| 虚拟电厂·负荷型（含负荷聚合商） | 参照售电公司/批发用户：报量不报价，具备条件后转报量报价 |

**分布式光伏可按月二选一** —— 这是自然人可以合法触及现货市场的路径（见 §10）。

| 时点 | 动作 |
|---|---|

## 3. 报价规格

### 3.1 火电与新能源（第三十四条）

- 单位：元/兆瓦时；**最多 10 段**；出力最小单位 1 兆瓦；电价最小单位 1 元/兆瓦时
- 首段出力起点 = 0，末段出力终点 = 装机容量
- 每段申报：出力起点、出力终点、区间价格
- **单调非递减**（随出力增加）；每段起点 = 上段终点；衔接点报价归**上一段**
- **同一运行日仅允许申报同一条报价曲线，96 个时段共用同一条曲线**（关键简化）
- 含配建储能者：首段报价对应容量需包含配建储能计划充电电力
- 煤电启动费用：冷态 > 温态 > 热态，单位万元/次，不超申报上限（附件 1-6）
- 出力上下限：申报 96 点最大/最小发电能力曲线
- 火电最早可并网时间：15 分钟精度
- 启停出力曲线：15 分钟间隔；未填报读典型曲线
- 迟报/漏报/不报 → **用缺省值**

**启动费用不纳入补偿的情况**（第三十四条 2）：申报非系统原因调试/试验计划或非系统原因必开；上次停机因自身原因跳闸/故障迫停；因自身原因未执行开机计划（偏差 ±2 小时视为未执行）；申请低谷消缺后开机；已在西北区域交易获得启停补偿。

### 3.2 用电侧（第三十五条）

- 售电公司/批发用户：申报运行日 **96 点用电需求曲线**（含线损电量）
- 申报电量上限 = 合同容量限额（兆瓦）× 1/4 × **L**，L = 1.17
- 售电公司代理用户关系**每日 7 点**从交易平台获取
- 日前缺省申报值 = 该时段持有的中长期合约电量
- 具备条件后转报量报价：最多 **5 段**，随负荷增加**单调非递增**，最大需求不超报装容量

### 3.3 独立储能（第三十七条）

- D-1 **上午 8:45 前**完成运行日申报（可通过交易平台）
- **报量不报价**：申报 96 点充放电功率（兆瓦）
- 充电按**用户侧**交易单元申报，放电按**发电侧**交易单元申报
- **每个自然小时内 4 个时段只能选一种身份**
- 放电：[0, 额定放电功率]；充电：[-额定充电功率, 0]；**未填视为 0**
- 报量报价时（逐步）：充放电各最多 5 段；充电功率取负值，首段起点 = 额定充电功率、末段终点 = 0；放电功率取正值，末段终点 = 额定放电功率；**随出力增加非单调递减**
- 需申报：最大/最小充放电功率、最大/最小允许荷电状态（%）、运行日末期望荷电状态上下限、意向充放电时段（15 分钟）、首次参与需申报运行日起始荷电状态

### 3.4 机组参数（第三十九条，向调度提供）

1. 额定有功功率（新能源 = 全厂装机容量），兆瓦
2. 最小稳定技术出力（仅火电），兆瓦
3. 有功功率调节速率 = 最大爬坡速率，兆瓦/分钟
4. 厂用电率 = (1 − 上月度实际上网电量/上月度实际发电量) × 100%
5. 最小连续开机时间
6. 最小连续停机时间
7. 独立储能：额定功率（兆瓦）、充放电效率（%）
8. 调度所需其他参数

**缺省量价参数**（第四十条）：注册时提供；未按时申报则用缺省值出清；**一月内允许改一次**，每月底前 3 个自然日内申请。

## 4. 出清机制（第四十五条、第四十八条、第六十条）

### 4.1 日前两步

1. **SCUC** —— 算运行日 96 点机组启停计划
   目标：运行日全时段**发电成本最小化**
   约束：负荷需求及外送计划、备用容量需求、输变电设备及断面传输容量极限、机组出力上下限、爬坡速率、最小连续开停机时间；同时考虑机组报价
2. **SCED** —— 算运行日 96 点机组出力曲线 + **分时节点电价**
   目标：同上；约束同上（不含最小连续开停机）

- 新能源**同报价**时：按各主体同报价段的**申报容量比例**分配
- 数学模型：附件 1-2（SCUC）、附件 1-3（SCED）
- 无可行解时按附件 1-7 松弛惩罚因子处理

### 4.2 实时

SCED（无 SCUC），机组组合基本确定；约束含超短期负荷预测与备用需求；目标为**社会福利最大**。

### 4.3 特殊机组出清（第四十六条）

| 类型 | 规则 |
|---|---|
| 必开机组 | 必开时段状态为开机，**不参与机组组合优化**；必开最小出力接受出清节点电价（未指定则取最小稳定技术出力）；以上部分按报价参与优化。**仅中标必开最小出力时不参与市场定价** |
| 热电联产 | 供热电力负荷下限接受节点电价、不参与优化；下限至上限之间按报价参与。**仅中标下限时不参与市场定价** |
| 调试（试验）主体 | 不参与优化，接受出清节点电价 |
| 开/停机过程 | 升功率至最小可调出力期间（或降功率至解列期间）按申报/典型曲线，不参与优化，接受节点电价；达到最小可调出力后**从下一时段起**按报价参与 |

## 5. 定价（第五十条、第五十一条、第六十四条、第六十五条、第十八条、第二十条）

- 出清形成**每 15 分钟**节点电价
- 小时内 **4 个 15 分钟节点电价的算术平均** = 该节点**小时平均节点电价**
- **发电侧**：以机组**所在节点**的小时平均节点电价结算
- **用户侧日前统一结算点电价** = 发电侧所有节点日前出清电量与日前节点电价的**加权均值**（按小时）
- **用户侧实时统一结算点电价** = 发电侧实时出清电量与实时节点电价**所有节点加权平均**（按小时）
- 多调度单元对多结算单元：按每小时上网电量比例拆分；无上网电量则按注册容量比例；反向（多调度单元对 1 结算单元）按电量加和、电价加权平均，出清电量全为 0 时取算术平均

## 6. 结算（结算部分）

### 6.1 模式

- **日清月结**：以**小时**为基本计算时段，以**日**为电费计算周期，出具**日清分临时结果**，以**月度**正式结算
- 日清分临时结果遇周六日/节假日**顺延至下一工作日**（具备条件后改每日发布）
- 结算方式采用**方式一**：现货全电量按现货市场价格结算，中长期合同电量按「中长期合同价与中长期结算参考点现货价的**差值**」结算
- **中长期结算参考点暂按用户侧日前市场统一结算点电价执行**
- 用电量按国家发布的综合线损率折算线损后作为实际结算用电量
- 转供/关联关系产生的负电量**按负电量结算**

### 6.2 发电侧电费（第二十八条）

```
R电能 = R省内日前 + R省内实时 + R中长期合约 + R省间日前 + R省间日内 + R调平发电

R省内日前   = Σ(Q省内日前,t × P省内日前,t)
R省内实时   = Σ(Q省内实时,t × P省内实时,t)
              Q省内实时,t = t 时段实际上网电量 − (省内日前出清 + 省间日前结算
                             + 省间日内结算 + 省间互济 + 省间调峰辅助 + 省间备用辅助) 的差额
R中长期合约 = Σ[Q中长期合约,t × (P中长期合约,t − P中长期参考点,t)]
              P中长期参考点,t = t 时段用户侧日前市场统一结算点电价
R省间日前   = Σ(Q省间日前,t × P省间日前,t)
R省间日内   = Σ(Q省间日内,t × P省间日内,t)
R调平发电   = Q调平发电 × P月度实时   (P月度实时 = 实时市场按月度全节点加权均价)
```

### 6.3 用电侧电费（第二十九条）

```
C电能 = C合约 + C日前 + C实时 + C调平用电
C日前 = Σ[Q日前,t × P日前,t]           P日前,t = 日前市场 t 时段统一结算点电价
C实时 = Σ[(Q实际,t − Q日前,t) × P实时,t]  代理购电工商业还需扣减调试电量
```

### 6.4 独立储能结算（第十六条）

- 放电参照**发电侧**（用**节点电价**）、充电参照**用户侧**（用**用户侧统一结算点电价**）
- **暂不参与**：市场结构平衡费用分摊及返还、用户侧中长期偏差收益回收及返还、发电侧中长期偏差收益回收及返还
- 日前或实时出清充放电方向与结算单元不一致时，**不一致方向按 0 结算**

### 6.5 结算流程（第二十五条、第二十六条）

| 时点 | 动作 |
|---|---|
| D-1 | 调度将 D 日省内日前出清结果推送交易机构 |
| D+1 | 调度推 D 日实时现货/辅助服务/省间结算量价；电网推 D 日各主体**每小时电量** |
| D+3 | 调度推调频辅助服务费用、机组考核费用 |
| **D+5** | **交易机构发布日清分临时结果** |
| D+5 起 24 小时内 | 经营主体核对，异议须 24 小时内反馈；交易机构 24 小时内反馈数据提供部门；逾期视为无异议 |
| 每月月底前 | 电网按现有数据预估发电企业结算电费与代理购电费用 |
| 次月初（数据完整后 2 工作日内） | 交易机构算市场结构平衡费用**预估值**，纳入批发用户/售电公司结算依据 |
| 次月中下旬 | 完成发电侧、代理购电实际结算，算**正式**市场结构平衡费用；批发用户/售电公司差额在次月分摊或分享 |

**结算数据交付方式**：交易机构通过交易平台单独推送结算明细与依据，**公开计算示例和说明**，推送"应采用**数据接口**等便于经营主体使用的方式"（结算部分第三条（一））。

## 6.6 市场分摊及返还费用（结算部分第五章）

原则：**谁产生、谁负责，谁受益、谁承担**。

| 类别 | 构成（第三十四、三十五条） |
|---|---|
| 市场平衡类 | 市场结构平衡费用、**阻塞平衡费用**、省间双轨制不平衡资金 |
| 市场运营类 | 机组考核费用、火电机组成本补偿费用、用户侧现货偏差收益回收、用户侧中长期偏差收益回收、发电侧中长期偏差收益回收 |

四舍五入偏差电费：以月度为单位，由所有参与结算主体按月度实际结算电量分摊或返还。

### 6.6.1 市场结构平衡费用（第三十七~四十一条）

```
R市场结构平衡费用 = R非市场偏差电费 + R市场偏差电费 − R阻塞平衡费用 − R省间中长期差价

R非市场偏差电费 = Q非市场月度偏差电量 × P非市场偏差
   P非市场偏差 = 250 元/兆瓦时
   Q非市场月度偏差电量 = Q上网电量 − Q省间实际结算电量
                        − (Q实际结算用电量 − Q电网代购调试电量)
                        − Q优先合同电量 − Q市场化发电企业调试电量

R市场偏差电费 = R用电侧电能量电费 − R电网代购调试电量电费
              − (R发电侧电能量电费 − R省间实际结算电量电费
                 − R优先合同电量电费 − R市场化发电企业调试电量电费)
              + R用户侧偏差收益回收 + R发电侧偏差收益回收

R省间中长期差价 = Σ Q省间中长期实际结算电量,i,t × (P中长期参考点,i,t − P省内日前,i,t)
```

- 分摊范围：所有市场主体，按当月上网电量或用电量占比；用户侧含电网企业代理购电和批发用户（含售电公司）；**月结月清**
- **现货市场全月结算时，用户侧与发电侧的各时段偏差收益回收不再执行**（第四十一条）——即上式末两项在满月结算时归零
- 主体注销/退出时，其份额由其他主体按占比分摊

### 6.6.2 阻塞平衡费用（第四十二条）

存在原因：**发电侧按节点电价结算、用户侧按统一结算点电价结算**，两者应收应付差额即阻塞平衡费用。

```
R阻塞平衡费用,i = Σt [ Q省内实时,i,t × (P实时统一,t − P实时,i,t) ]
```

- **按小时计算、按日返还**
- 分摊主体：所有参与现货结算的经营主体（批发用户、售电公司、发电企业、电网企业代理购电、独立储能），按**日实际结算电量**分摊或返还

### 6.6.3 省间双轨制不平衡资金（第四十三条）

来源：跨省调峰浅调不平衡电量、跨省备用辅助服务（未落实至经营主体部分）、日前实时送出电量、直流通道波动偏差电量等省间未清分成分；省外按省间交易价格结算、疆内按非市场偏差价格平衡，两者差额即双轨制资金。

```
R省间双轨制 = Q省间外送 × (P省间外送结算 − P月度实时)
```

由疆内市场结算的发电企业按**月度外送实际结算电量比例**分摊或分享。

### 6.6.4 用户侧现货偏差收益回收（第四十五、四十六条）

- 按小时统计回收、按月返还
- 偏差率 L = |Q申报 − Q实际| / Q实际；**L0（允许最大申报偏差率）暂定 20%**
- 实际结算电量为 0 而申报不为 0 时 **L 为无穷大**，回收该时段全部对应收益
- 回收公式：
  - 若 `Q申报 > Q实际 × 1.2` 且 `P实时 > P日前`：`R回收 = [Q申报 − Q实际×1.2] × (P实时 − P日前)`
  - 若 `Q申报 < Q实际 × 0.8` 且 `P实时 < P日前`：`R回收 = [Q实际×0.8 − Q申报] × (P日前 − P实时)`

### 6.6.5 用户侧中长期偏差收益回收（第四十七、四十八条）

- 判据：月分时累计中长期签约比例 **< 60% 或 > 120%**（代理兵团/增量配电网工商业用户的售电公司及电网企业按 20% 偏差限值、月度峰谷时段执行）
- 回收系数 K = 1
- `Q中长期 < Q实际×0.6` 且 `P中长期 > P日前`：`R回收 = (P中长期 − P日前) × (0.6×Q实际 − Q中长期) × K`
- `Q中长期 > Q实际×1.2` 且 `P中长期 < P日前`：`R回收 = (P日前 − P中长期) × (Q中长期 − 1.2×Q实际) × K`

### 6.6.6 发电侧中长期偏差收益回收（第四十九条）

- **未纳入机制**主体：签约比例 < 80% 或 > 120% 触发
  - `Q中长期 < Q实际上网×0.8` 且 `P中长期 < P日前`：`R回收 = (P日前 − P中长期) × (0.8×Q实际上网 − Q中长期) × K`
  - `Q中长期 > Q实际上网×1.2` 且 `P中长期 > P日前`：`R回收 = (P中长期 − P日前) × (Q中长期 − 1.2×Q实际上网) × K`
- **纳入机制**主体（136 号文机制电量）：阈值改为 `0.8×(1−机制比例)`；**机制比例 = 月度机制电量 / 月度上网电量**（同一结算单元下多机组机制比例不同时按此算）
- K = 1

## 6.7 追退补与清算（结算部分第四章）

| 项 | 规则 |
|---|---|
| **追退补** | 因经营主体原因 / 数据异常 / 其他规则允许情形，对已结算电量电费重算，在后续周期多退少补 |
| **追溯期** | **原则上不超过 12 个月** |
| **清算** | 因政策或规则调整等，对已结算电量电费重算，在后续周期多退少补 |
| 日清分核对期、月度账单发布前 | 可直接重算相应日期和小时的电能电费及分摊返还费用 |
| 月度账单发布后 | 中长期合同数据异常 → 按正确与错误的中长期合同电费差值结算退补；电量计量异常 → 调整电量按数据异常月份实时全节点月度加权均价结算，产生的市场结构平衡费用在该月清算 |
| 省间双轨制及市场运营费用异常 | 追补正确费用后，在最近一次结算中计入相应费用分摊 |

## 6.8 其他事项（结算部分第六章）

- 售电公司未按时足额缴纳履约保函/保险且经书面提醒仍拒不足额缴纳 → 取消后续交易资格；已签未履行合同可通过平台转让，未转让的暂停结算执行；在电力交易平台与"信用中国"等公示；公示后依法对法定代表人、自然人股东及相关人员实施失信惩戒
- **连续 12 个月未进行实际交易**的售电公司：交易机构征得地方主管部门同意后暂停交易资格，重新参与前须再次公示
- 售电公司须向用户说明现货价格及到户价格构成，**不得以中长期合同价代替现货价格**
- 用户可自主选择售电公司，**可在次月更换**并签订零售合同（套餐）

## 6.9 电量数据拟合规则（结算部分附件）

计量装置 96 点示值曲线数据缺失时的补全规则（用于结算）。

**异常示数校核**：
- 每日 0 时日冻结值应完整准确，采集不成功则补采或现场补抄
- D 日 0 时曲线值须等于 D 日 0 时日冻结值；D 日 24 时曲线值须等于 D+1 日 0 时日冻结值。不等时以日冻结值替代
- D 日 24 时曲线值须 ≥ D 日 0 时曲线值，否则删除该点补采/补抄；核实为表故障按计量故障处理
- 以 0 时、24 时两点为基准，删除之间不合逻辑的异常数据（小于 0 时值、大于 24 时值、整点示数小于前一整点等）

**缺失示数拟合**：
- 连续缺失 **≤ 3 点**：取缺失整点前后时刻示值之差**等差分摊**，单调递增方式拟合
- 连续缺失 **> 3 点**：该日缺失曲线全部根据**前 7 日同一时刻**各整点数据（含拟合数据）的变化趋势修正补全；前 7 日同一时刻有缺失则该日不参与趋势计算；前 7 日均无完整曲线则按上一条规则拟合
- 电能表停运期间按停运前最后一个整点数据补全；旧表拆除至当日 24 时按拆表时底码补全；新表安装按起始数据补全
- **用于结算的拟合数据单独保存，采集系统原始数据不改**

## 7. 煤电机组成本补偿（第七章）

- 分**机组启动补偿** + **机组运行补偿**；**按日统计、按月结算**
- 分摊主体：所有参与现货结算的经营主体（批发用户、售电公司、发电企业、独立储能充电电量、电网企业代理购电等），按**月度实际结算电量比例**分摊
- **分摊上限 γ = 0.005 元/千瓦时**，超出部分由获得方按比例削减
- ⚠ **运行初期只统计、暂不实际补偿结算**（第七十条）——后期结合运行情况、用户侧承受能力、确定分摊主体后适时实施

### 启动补偿（第七十一条）

```
R启动,i = Σ Pi,d启动        Pi,d启动 = 机组 i 月内 d 日启动对应的启动费用报价
```
实际启动状态由调度自动化系统记录的启停机时间认定。

### 运行补偿（第七十二条）

```
R运行补偿,i,d = max{ Σt [ (Ri,t电能成本 − Pi,t实时) × Qi,t实际 × h ], 0 }
```
- `Qi,t实际`：d 日 t 时段煤电机组 i 的实际上网电量
- `Ri,t电能成本`：**取「基于核定变动成本 α 计算」与「基于申报量价曲线计算」两者中的较小值**
- `Pi,t实时`：d 日 t 时段该机组实时市场节点电价
- `h`：运行补偿系数（h ≤ 1）
- ≈ 出力下限相关项涉及 `pi灵活性改造下限` 与 `pi申报下限`（机组灵活性改造出力下限 / 运行日申报出力下限平均值）⚠ 公式转写失真，须回原文核对

### 不补偿（第七十三条）

- 实际出力超出 AGC 下发指令 **且偏差量 > 指令值的 β 倍**（β = 5%）的对应时段
- **未准入现货市场的煤电机组**

## 8. 考核与市场力

### 发电侧考核（第八章）

- 非计划停运：按"两个细则"执行；认定规则见第七十五条（因自身原因跳闸/被迫停运、未按时并网且偏差 2 小时以上）
- 实时发电计划执行偏差：每交易时段用 AGC 采样实际出力与发电计划比较，算每分钟偏差量 P偏差

### 市场力监测（第九章）

| 参数 | 含义 | 取值 |
|---|---|---|
| R1 | 剩余供给指数限定值 | 1.0 |
| R2 | 报价集中度价格统计范围 | 集团最高报价【80%，100%】 |
| R3 | 报价集中度容量统计范围 | 50% |
| R4 | 事前市场力监测参考价格 | 前 30 天（不含当日）所有市场化火电机组**剔除 5% 极端高价和 5% 极端低价**后的申报均价 |
| C | 事后市场力监测参考价格 | 疆内燃煤基准价格的 **1.5 倍** |
| M | 新能源超短期功率预测偏差限定值 | 1.05 |

**事前检测（第八十四~八十六条）** —— 日前出清前逐时段执行：

1. 算各发电集团**剩余供给指数 RSI**；若 RSI < R1(=1.0) 则触发该集团报价检测
   ```
   RSIi,t = [ Σ(j≠i) Qj,t + Σ(n) Tn,t − Dt + St ] / Qi,t
   ```
   `Qj,t` = t 时刻全网第 j 台市场化开机机组可发电容量；`Qi,t` = 第 i 个集团市场化开机机组可发电容量；
   `Dt` = t 时段系统负荷；`Tn,t` = 联络线 n 在 t 时段计划功率（送入为正、输出为负）；`St` = t 时刻非市场化电源出力计划
2. 统计该集团 t 时刻市场化开机机组**申报容量之和** Q总,t
3. 统计与集团最高报价相同或接近（在 R2 范围内）的火电机组申报容量 Qmax,i
4. 若 **Qmax,i > Q总,t × R3(=50%)** → 认定该集团在日前报价阶段行使市场力，**将该集团所有市场化开机火电机组高于 R4 的报价按 R4 替换**（替换后价格参与申报均价计算）
5. 替换后的报价参与日前/实时出清，**出清结果即结算依据**

**新能源预测跳变检测（第八十七条）**：调度监测全网新能源场站超短期功率预测申报曲线；若某时段预测值 > 前后相邻两时段预测**平均值的 M(=1.05) 倍**，则用前后两时段均价替换，替换后曲线为有效超短期预测。

**事后处置（第九十条）**：日前出清后算发电侧 96 点出清加权均价，若 > C 则触发管控，按 C 与该均价的**比例调减**发电侧各节点 96 点出清电价，用调减后电价结算。
