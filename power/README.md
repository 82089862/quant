## 目标市场：新疆电力现货

### 市场事实（已验证，2026-10-12 查）

- **2025-10-11** 新疆电力现货市场转入连续结算试运行（新疆能源监管办）。
- **2026-09-01** 发布《新疆维吾尔自治区电力现货市场试运行工作指引 5.0 版》，即日起组织连续结算试运行。
- **2026-09** 完成首次多月直接交易，建成数年 / 年度 / 多月 / 月度 / 月内全周期品种体系。
- 结算用**统一结算点价格**（指引措辞），不是节点电价。
- 新型经营主体已入市：独立储能现阶段**报量不报价**（逐步转报量报价）；源网荷储一体化、绿电直连按用户侧身份参与；虚拟电厂逐步参与。
- 新疆特有制度：**火电机组成本补偿机制**（新能源挤压下火电开机即亏）、**新能源可持续发展价格机制差价结算**。

## 技术路线（C 方案：开源建模）

**不从 pandapower 潮流起步。** 新疆电网真实拓扑不公开，且省级现货出清是「报价曲线 + 简化安全约束」、统一结算点结算 —— 用 IEEE 节点系统是在解一个新疆不存在的问题。

起点：**PyPSA 的 `demand-supply-bids` 出清示例**（供需报价、均匀价格拍卖、含可下载 notebook），改造成新疆版。

必须改造的 6 处：

1. **结算机制** → 改统一结算点（示例是分区报价、分区电价）
2. **新能源** → 风电 / 光伏装机占比极高，重点是**大发时段的价格塌底**（午间光伏顶峰，价格可能探零或为负）
3. **火电** → 必须实现成本补偿机制（欧洲模型里没有对应物）
4. **独立储能** → 现阶段**报量不报价**，当价格接受者，不进报价策略层
5. **外送** → 疆电外送直流配套电源，先当固定曲线，需确认是否参与现货定价
6. **中长期衔接** → 中长期合约与现货的分解关系，直接影响收益计算

## 已知卡点

1. **数据是瓶颈，不是算力。** 规则书好拿，**逐时历史价格与负荷序列**才是真门槛。动工前先花半天自查新疆电力交易中心信息披露平台，确认能拿到什么。
2. **不能直接套欧洲出清机制。** PyPSA 示例是 uniform-price auction（分区耦合），中国是集中竞价 + 全电量出清 + 各省细则差异；新能源入市规则也不同。学到的是出清**骨架**，规则约束必须自己抄市场细则。
3. **个人不能开户。** 电力市场是市场主体准入制（发电企业 / 售电公司 / 电力用户 / 储能 / 虚拟电厂）。现实路径：进市场主体做策略，或做策略 / 预测 / 仿真系统供应商。
